# 改进论文流程（你的特殊需求：原优秀论文 → 改进稿）

> 需求回顾：你让我分析一篇**往年国赛优秀论文** → 找不足 → 改出**改进论文**。
> 改进论文须：① 指出原论文不足；② 含「修改总概况」；③ 其余按正常国赛论文结构写。
> 本流程把这件事固化，以后你发"原论文+题+数据"，我直接产出。

## 输入（你给我）
1. **原题**（赛题或题目 PDF）
2. **原优秀论文**（你要改进的 that one）
3. **数据集**（如有；没有就基于原论文给出的数据/假设）

## 步骤

### Step 1 — 精读原论文，提炼结构（我做）
- 用 `02_Claims-Evidence矩阵` 反向拆原论文：它主张什么、证据够不够。
- 标出"假设 / 模型 / 求解 / 结果 / 表述"五段。

### Step 2 — 找不足（我做，按维度）
按以下维度挑刺（对标 `05_评审清单` 但更针对"优秀论文还能怎么更好"）：
- **假设**：有没有可放宽 / 更贴合实际的假设？
- **模型**：有没有更优/更新/更简洁的建模方法？
- **求解**：计算是否可优化、是否有数值稳定性问题？
- **结果**：灵敏度/误差分析是否缺失？对比是否充分？
- **表述**：是否符合 `04_写作铁律`？有无 AI 痕迹？图表是否规范？
- 输出：`原论文不足清单.md`（每条含"位置 + 问题 + 改进方向"）。

### Step 3 — 写「修改总概况」（我做）
一段总览：原论文整体水平、主要短板、我改了哪几点、预期提升。放在改进论文**开头（摘要之后/正文之前）或独立章节**，明确标注"修改总概况"。

### Step 4 — 产出改进论文（我做）
- 结构 = 正常国赛论文（问题重述→假设→模型→求解→结果→评价→结论）。
- 在对应位置嵌入"原不足 + 我的改法"（可加旁注/批注形式，或融入正文）。
- 守 `04_写作铁律`；数字可追溯。
- 末尾或开头含「修改总概况」+「原论文不足清单」引用。

### Step 5 — 自动评审（我当审稿人）
- 按 `05` 评审改进稿，迭代到定稿。

## 改进论文成品结构（建议）
```
标题
摘要
关键词
【修改总概况】            ← 必须
一、问题重述
二、模型假设与符号
三、模型建立与求解        ← 含"相较原论文的改进"标注
四、结果与分析
五、模型评价与改进
六、结论
附录：原论文不足清单      ← 必须（或正文引用）
参考文献
```
