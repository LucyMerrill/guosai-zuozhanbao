# 25_流程图绘制SOP（draw.io 路线）

> 2026-08-29 新增。论文流程图（总体思路图 / 每问详细流程图 / 问题分析横排图）首选本路线：主 agent 手写 draw.io XML → CLI 逐页导出 300dpi PNG。与 23 号 §3 的 matplotlib 3×3 固定模板互补：本路线版式直接对标国奖优秀论文（黑白高密度、评审观感好），且交付可编辑的矢量源文件；matplotlib 路线在无 draw.io 环境时兜底。

## 0. 适用与分工

- 用途：④ 问题分析章流程图（stage4 任务 4）、总体思路/技术路线图、答辩 PPT 结构图。
- 分工：**主 agent 亲自做**（单点作图不值得开子 agent）；写作子 agent 只负责在正文中写"如图 X 所示"引用与图注。
- 模板：`assets/示例_数模流程图风格.drawio`（三页 = 三种版式，均已视觉验收通过；内容取自 2023C 国奖卷，仅作版式示范，实际画时换成本题内容）。

## 0B. 数量与内容硬标准（C050 原则，2026-08-29 定）

用户明确要求（对标 C050 国一卷）：**全卷默认只画 1 张总体流程图**，放在开头问题分析处；分问详细流程图默认不画——仅当某问流程复杂到正文说不清时才补一张（版式 2），全卷流程图 ≤2 张。

**"画得充实、详尽、没有废话"的落地标准**（以 C050 图1 为标尺，约 25 格）：

1. **每格都是本题实货**：方法名具体到 "Spearman 相关 / K-means++ 聚类 / 模拟退火 / 灰色关联" 级别；禁止"数据分析""模型建立"这类空泛孤框——要么细化（写明做什么+判据），要么并进相邻框。
2. **两层结构**：每问分支 = 子问题（菱形）→ 分析对象框（品类分布/单品关联级）→ 具体方法框；不是一列泛框到底。
3. **体现问间衔接**：把"约束条件增多""框架复用"这类继承关系画进图（箭头跨问传递），评审能看出各问是一套体系而非多篇小论文。
4. **与摘要同构**：摘要每问段提到的主方法必须出现在图里对应分支；画完拿摘要逐问核对再交——图里多出摘要没有的方法、或摘要写了图里没有，都算图文不符（20 号雷点）。
5. **检验细节不上总图**：蒙特卡洛、交叉验证、灵敏度等放各问章节的检验小节；总图塞这些就是废话。

**边界（2026-08-29 用户强调）**："全卷一张"**仅约束流程图**。matplotlib 数据图不受此限——数量按 10 号 §3 基准（12~20 张）与 23 号 §2"每问 4~6 张"照常出，并遵守：单图单插（独立编号/图注、随文插，不拼大块）、组图最多 2 个子图且仅在一张图确实说不清时用、图型多样化、美观不偷懒（细则见 23 号 §2）。

## 1. 三种版式（先选题式再动笔）

| 版式 | 模板页 | 适用场景 | 特征 |
|---|---|---|---|
| 竖向树状总体思路图 | 页1 | **总体流程图默认版式**（C050 同款） | 左列三阶段 → 问题框 → 菱形分支 → 方法链，右侧大括号归纳问题类型 |
| 三列详细流程图 | 页2 | 单个问题的完整流程（数据→分析→检验） | 三列纵向链 + 跨列衔接 + 菱形判断"是/否"分支 |
| 横向虚线分组图 | 页3 | 问题分析章总览（多问并列，stage4 任务 4 的主用版式） | 虚线容器横排 + 浅蓝标题条 + 容器间空心大箭头 |

- 复杂问题一问一张详细流程（版式 2），总览合一张（版式 1 或 3）；禁左右大片空白的竖向"死亡图"（stage4 任务 4 硬约束）。

## 2. 风格硬约束（照抄模板样式，不自创）

- 黑白白底：`fillColor=#FFFFFF;strokeColor=#000000;strokeWidth=1`；分组标题条浅蓝 `#dae8fc/#6c8ebf`（浅色不刺眼，黑白打印安全）。
- 字号 11~12；每框 ≤12 字（版式 3 每框 ≤8 字）；框 170×28，纵向步距 44（框 28 + 间隙 16），菱形 150×44。
- 连线统一：`edgeStyle=orthogonalEdgeStyle;endArrow=block;endSize=4`；判断分支必须标"是/否"（`fontSize=10;labelBackgroundColor=#FFFFFF`）。
- 坐标纪律：按固定网格手写坐标（模板就是坐标参考），不用自动布局，导出前先算好行列。
- 流程图内**不写具体数值/结果数字**——数字与 `all_results.json` 不同步是 24 号雷点。

## 3. 生成流程（主 agent 5 步）

1. **取材**：从 研究契约.md / 模型方案.md / RESULTS_q*.md 提取该问步骤链（数据→方法→检验→输出）。
2. **手写 XML**：复制模板中最接近的一页改文字；新增框按 44 步距排坐标；id 沿用 b101/b102 风格顺延。
3. **导出**：`python scripts/export_drawio_png.py 图.drawio -o 预览目录`（`--scale 2` 检查用；交论文用 `--scale 3` ≈300dpi）。
4. **检查**：先按 23 号 §2.5 成图验收清单自查渲染成品，再交 judge 子agent 视觉验收（或按 §4 自查）；FAIL 改坐标重导，直到 PASS。
5. **交付**：`.drawio` 源文件 + PNG 放 `工作目录/figures/`；图注在 md/Word 里另加（图下方、≤15 字、禁公式）。

## 4. 出图前自查清单

- [ ] 文字无溢出/截断（中文字宽≈字号，框宽 ÷ 字号 ≈ 可容字数）
- [ ] 无连线穿框、无断箭头，分支"是/否"标签齐全
- [ ] 与正文一致：模型名、步骤顺序与 chapters/*.md 对得上；无错别字（国奖卷把 Spearman 拼成 Sperman 是反面教材，别学）
- [ ] 图内无标题文字（图题在图注）、无具体数值
- [ ] 黑白打印仍可读

## 5. draw.io CLI 速查

本机安装位置 `D:\drawio\draw.io\draw.io.exe`（换机器先 `where draw.io` 或查注册表确认）。

```
# 导出第 n 页 PNG（页码从 1 开始！v27.0.2 之前才是 0 起）
draw.io.exe -x -f png -p 1 -s 3 -o out.png 输入.drawio
# -s 放大倍数：2 供检查，3 ≈ 300dpi 供论文插图
# 全部页导一个 PDF：-x -f pdf -a -o out.pdf 输入.drawio
```

用户手动微调：app.diagrams.net（网页版）或桌面版打开 `.drawio`，改完用编辑器导出（PNG 勾 300 DPI）。

## 6. 与 23 号的关系

- 23 号 §3 matplotlib 3×3 模板：兜底路线（比赛机器无 draw.io、或需在求解代码里程序化批量出图时用）。
- 本路线优点：矢量源文件可改、版式对标优秀论文、CLI 导出 300dpi 简单可靠。
