## 一句话定位

选型/检验用的**查询字典**：21 号与 solver 技能管"选什么模型"，22 号管"流程与必做检验"，本字典管"选定某模型后的数据要求、关键假设、禁忌点、缺陷、检验方法"——尤其补冷门模型的广度。

## 怎么用（agent 比赛中只用脚本）

**选型口径（2026-09-05 定版，与 stage2 同步）**：选型以题目适配+可解释+可核验为准，主流方法是低风险默认而非强制；本字典的角色是**新方法的保险丝，不是新方法的禁区**——想用冷门/非主流方法，先 `--only-ok` 查它的关键假设与禁忌点、过 21 号三问自查、在③选拔赛赢过主流基线，冷门就是差异化优势；查都不查就上，冷门就是事故。新颖度落在结构层（目标/约束/耦合机制），不落在标签层（变体堆砌），全卷预算 1~2 处亮点。

```bash
python scripts/query_model_dict.py 熵权法               # 完整条目+审核结论，可信优先
python scripts/query_model_dict.py "GM(1,1)" -n 3       # 全角/半角括号已自动归一
python scripts/query_model_dict.py 灰狼 --field 禁忌点   # 只看某字段
python scripts/query_model_dict.py 熵权法 --only-ok      # 只要可信条目（选型默认建议开）
python scripts/query_model_dict.py --stats              # 审核总览
python scripts/query_model_dict.py --group 灰色系统预测  # 分组内所有模型（带等级标记）
```

- **stage2 建模**：选型后 `--only-ok` 查一次条目，把"关键假设+禁忌点"并进研究契约对应问的假设论证
- **stage5 评审**：按条目"检验方法"列核对论文检验是否做全（缺失计 WARN、核心检验缺失计 FAIL）
- 14 号编译、27 号复盘等环节不受本字典影响
