# A/C 题国赛获奖论文学习报告（2021–2025）

> 目的：把桌面 `2021-2025高教社杯全国大学生数模竞赛优秀论文.zip` 里 A题(13篇)、C题(14篇) 化为知识，对比「国赛作战包」既定标准找差距，为下次国赛流程做准备。
> 样本：27 篇 PDF 已解压至 `国赛获奖论文_A_C/`；批量提取摘要+前2页判题型；精读两篇标杆——**2024 A 板凳龙（江南大学）**、**2023 C 蔬菜定价（C228）**。
> 结论先行：作战包的方法论骨架（契约→建模→求解→写稿→评审）是对的，但**三个写作章节缺失 + 灵敏度/基线对比偏弱 + 缺附录代码**，是和真实国奖论文最明显的差距。

## 一、A题 五年题型与共性方法论

| 年份 | 题目 | 核心方法 | 特点 |
|------|------|----------|------|
| 2021 | （扫描版，机理/信号类） | — | 文本提取不到，留待需要时精读 |
| 2022 | 波浪能发电最大功率 | 牛顿定律 ODE（拉普拉斯/Runge–Kutta）+ 单目标优化 | 解析+数值双解对照 |
| 2023 | 定日镜场优化 | 光学效率机理（余弦/遮挡/截断）+ 单目标优化（蒙特卡洛/三分查找） | 空间向量、光线离散化 |
| 2024 | 板凳龙路径与速度 | 螺旋线几何 + 二分法递推 + 分离轴定理(SAT)碰撞 + 优化 | 纯几何+编程，可视化强 |
| 2025 | 无人机烟幕协同 | 四维运动学 + 非线性规划 + 差分进化/模拟退火 | 高维"黑箱"优化 |

**A题共性**：物理/几何**机理建模** → 解析或数值求解（ODE / RK4 / 二分 / 积分）→ 以某指标最大/最小做**优化** → **数字精确到多位小数**（板凳龙 412.4738376821458 s，12 位）→ **强可视化**（路径、场分布、碰撞排布）。
**A题难点**：物理/空间直觉要求高；几何与光学类（定日镜、板凳龙）需较强空间建模；数值精度极严，算错一处全盘崩。

## 二、C题 五年题型与共性方法论

| 年份 | 题目 | 核心方法 | 特点 |
|------|------|----------|------|
| 2021 | （扫描版，订购与运输） | — | 文本提取不到 |
| 2022 | 古代玻璃成分鉴别 | 统计 + 化学动力学微分方程 + 聚类(kmeans) + 判别(Logistic/Fisher) | 数据驱动分类 |
| 2023 | 蔬菜动态定价与补货 | 数据预处理 + ACF时序分解 + LSTM预测 + 价格弹性 + PSO/NSGA-II | 脏数据→ML→优化 |
| 2024 | 农作物种植策略 | 多阶段规划 + 蒙特卡洛 + 遗传算法 | 约束复杂、滚动规划 |
| 2025 | NIPT 时点与异常判定 | 随机森林/弹性网络 + B样条 + Logit + 动态规划 | ML + 优化 + 检验 |

**C题共性**：真实**脏数据** → **大量预处理**（清洗/编码/聚合）→ 统计/ML/时间序列 → **优化决策**（规划/PSO/NSGA-II/VIKOR）。
**C题难点**：数据清洗规则设计（3σ、分类规则）；方法选型多、需结合领域知识解释；但**模型无唯一解、容错高、易出彩**。

## 三、获奖论文的"质量标杆"（从两篇精读提取）

1. **结构完整且固定**：摘要 → 一、问题重述（背景+要求） → 二、问题分析（**逐问拆解+流程图**） → 三、模型假设 → 四、符号说明 → 五、数据预处理（C题类） → 各问题"模型建立与求解"（5.x 小节） → 结果展示（三线表+图） → 灵敏度/误差分析 → 模型评价与改进 → 参考文献 → **附录附完整 Python 代码**。
2. **"问题分析"独立成章 + 流程图**（图1 各问题递进关系）—— 这是作战包完全没有的章节。
3. **数据预处理独立成章**（C题）：分"整合 / 分析 / 异常 / 无关"四步，含 3σ 法则、分类规则、字符串匹配（fuzzywuzzy）。
4. **图表极密且自解释**：C题 问题一就 14 张图；图题 ≤15 中文字、全中文 label、有 (a)(b) 子图、每张图紧跟文字解读—— 与 `04` 铁律一致，但他们做得更密。
5. **数字精确、可追溯、可复现**：结果存 `result1~4.xlsx`，正文表与文件一致；附录放**完整可运行代码**（import / 读数据 / 求解 / 出图），用 numpy/scipy/pandas/statsmodels/pyswarms。
6. **与基线对比、说明提升**：C228 "与一般收益情况对比，发现收益明显提升"；A题 "精度极高，不必用弧长公式"—— 主动证明自己方法优于朴素法。
7. **关键词规范**：`关键词：方法1；方法2；…`（我们 `04` 铁律要求 `**关键词**：`，更严，保留）。

## 五、选题意略（开赛由我看，这里给判断框架）

- **队长能力**：工科、自学 AI 偏自动化、pandas/OpenCV、准大二。
- **A题**：需物理/几何机理 + 数值计算。板凳龙类"纯几何+二分"其实编程友好；但定日镜(光学)、烟幕(高维优化)对空间/数值功底要求高，且精度极严。
- **C题**：数据驱动，贴合他的 AI/自动化方向；模型开放、容错高、评委重"预处理严谨+方法合理"而非"算得精"。
- **倾向**：**C题 通常更匹配队长**（方向契合 + 容错高 + 作战包 09 的"七类自检/存表"正好对应 C题 预处理+结果）。但**最终 A 或 C 由我开赛当天按"数据质量 + 模型明确度 + 队长可落地性"现场定**，不预先绑定。
- 注：2021 年 A/C 是扫描版水印，文本提取不到；若今年撞类似题型，需临时用 Read 看图像页精读。

## 七、A题 / C题 方法工具箱（速查，本机可跑）

**A题工具箱**
- 几何：极坐标/笛卡尔互转、向量、旋转矩阵（numpy）
- 微分方程：RK4、拉普拉斯（`scipy.integrate`）
- 优化/搜索：二分、遍历枚举、三分查找、蒙特卡洛
- 碰撞：分离轴定理(SAT)、凸多边形投影
- 智能优化：差分进化、模拟退火（`scipy.optimize.differential_evolution` / 自写 SA）

**C题工具箱**
- 预处理：pandas 清洗 / One-hot / 聚合（`groupby`）
- 时序：ACF、时间序列分解（`statsmodels.tsa.seasonal`）
- ML：随机森林、弹性网络、LSTM（`sklearn` / `keras`）
- 优化：线性/整数规划、PSO、NSGA-II（`scipy.optimize` / `pyswarms` / 自写）
- 评价：TOPSIS、VIKOR、熵权（`sklearn` + 自写）

> 本机已装：numpy/scipy/pandas/scikit-learn/opencv（D 盘 python）。statsmodels/pyswarms 按需 `pip install`（清华镜像）。
