# 国赛对话速查（极简口令 · 连续模式）

> 适用：开赛新窗口、你不想每步说"第几阶段"时。
> 核心原则：**阶段内部仍细分成 ①~⑥ 保质量，但你的口令只有三句——「开始 / 继续 / 有问题我直接说」**。
> 配套总流程见 `00_作战SOP.md`，新窗口激活见 `13_比赛实战说明书_新窗口也能跑通.md`。

---

## 一、你全程就这三句话

| 场景 | 你对我说 |
|---|---|
| **开跑** | `国赛。跑完整流程，题是：[题面全文]，数据在：[路径或说明]` |
| **我暂停等你时（最常见） | `继续` |
| **某处不对** | 直接说问题，例如：`③里的异常值处理我想看具体删了哪些行`、`摘要太虚，重写`、`这个分组标准不合理，重切` |

> 你**不用**说"第②阶段""第③阶段"——我会自动连跑，只在必须你拍板的节点停下问你。
> 你**只管看结果**：没问题就回「继续」，有问题就开口说，说完我改完再问你。

## 二、我自动连跑的路线 + 我会暂停的 4 个检查点

```
你说「跑完整流程」
  │
  ├─ 自动 ① 契约：读题→写研究契约+Claims矩阵（锁范围，不跑偏）
  ├─ 自动 ② 建模：选模型+写求解计划（按 07+ solver，守可解释性铁律）
  ├─ 自动 ③ 求解：跑数据+七类自检+数字进 all_results.json（按 09）
  │
  ⏸【检查点1 · 模型与数据确认】我把「模型方案 + 关键数字预览」给你看
  │     你回「继续」→ 默认认可方向/数据；你说问题→ 我改完再问
  │
  ├─ 自动 ④ 写稿：问题驱动结构一次性生成（按 10+04+paper，数字全取 JSON）
  │
  ⏸【检查点2 · 评审前快照】我把「论文.md 全文」给你看（或核心章）
  │     你回「继续」→ 进评审；你说问题→ 先改稿
  │
  ├─ 自动 ⑤ 评审：我当审稿人按 08+05+review 挑刺、迭代改稿
  │     （致命问题逼改；重要/润色问你）直到 致命=0 且 ≥85 分
  │
  ⏸【检查点3 · 定稿确认】我把「最终稿 + 评审打分表」给你看
  │     你回「定稿」→ 完成；你说"再改XX"→ 继续改
  │
  └─ ⑥ 交付：`build_docx.py` 转 .docx + `validate_docx_format.py` 校验（fail==0）
         ⏸【检查点4 · 提交终检】你按 123 条 + 脱敏（删校名/姓名/队号）逐项确认，人工在 Word 导出 PDF
```

**为什么只在这 4 个点停**：定题方向、数据真实性、论文成稿、最终交付，是国赛高 stakes 处，必须你拍板；其余机械连贯的工作我一口气干完，省你的精力。

## 三、几个必须记住的硬规矩（不用你每次提醒）

1. **PDF 编译走 ⑥ 主路线**：④ 我出 `论文.md`，⑥ `build_docx.py` 转 .docx、校验器 fail==0 后由你在 Word 里人工导出 PDF（cumcmthesis LaTeX 仅备选，见 14 号第六节）。
2. **只做 C 题（2026-09-05 定版）**：开赛当晚直接按 21 号 §1「40 分钟流程」破题，不再 A/B/C 横跳；`13b` 打分表仅当多渠道选题时备用。
3. **正式赛别用改进论文模式**：`06` 是练手往年论文用的，"修改总概况"别写进正式稿。
4. **数字来自 JSON**：论文里每个数都能在 `all_results.json` 找到，绝不手编——你不用管，我守。
5. **脱敏**：提交前删校名/姓名/队号，承诺书单独签字上传（赛前准备项，非流程缺漏）。

```

     补货成本降23%、损耗率降15.6%……方向和数据OK不？
你：继续
我：[自动跑④] → ⏸ 检查点2：论文.md 已生成（问题驱动结构+摘要+图表），要我看哪章？
你：摘要再看下，感觉指标写少了
我：[改摘要] → 改完：摘要补了「补货成本-23%、损耗-15.6%、客户满足度+8.2%」三指标。
     继续评审吗？
你：继续
我：[自动跑⑤ 评审3轮] → ⏸ 检查点3：最终稿评审 89 分（致命0），定稿？
你：定稿
我：好。⑥ 走完：.docx 校验通过，你在 Word 导出 PDF，按 123 条脱敏后提交。
```

## 五、和"逐阶段口令"的关系（备查）

如果你某次想**手动控制节奏**（比如只想先建模不想写稿），仍可说：
`按作战包跑第②阶段` / `按作战包跑第④阶段` —— 单阶段触发依然有效。
极简连续模式（「跑完整流程」+「继续」）只是把常用路径省成三句话，两者不冲突。
