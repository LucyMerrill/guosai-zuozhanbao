## 0. 对比数据（为什么 2025C 快）

| 指标 | 2025C 模拟（标杆） | 2024C 模拟（本次） |
|---|---|---|
| 总时长 | **6.46 小时**（连续） | 约 2 个自然日（含大量空转等待） |
| 用户介入 | **4 次** | 10+ 次（含 2 次催促、2 次纠偏指令） |
| 子 agent 数 | 23 个 | 约 15 个 |
| 主对话写文件 | **1 个**（纯编排） | 大量亲自写（改稿/补丁/拼装） |
| 返工 | 写作格式 1 次返工 | 问1 死锁崩溃重跑、问3 超时 13h、图片全丢、3 轮评审 |

**结论**：慢不在计算本身，而在 ①崩溃返工（问1 短视死锁≈5h、问3 超时）②串行等待空窗（波次间干等通知）③口径不预注册导致的重复求解 ④主对话亲自干活挤占编排。**用户裁定：精度优先、并行拉满**——不降配，把并行度与一次成型率提上去。

## 2. 提速 SOP（精度优先、并行拉满）

1. **预注册、一次成型**：求解前把"定稿口径"（窗口限时、滚动结构、N₁、灵敏度点数、种子）写成配置并冻结，**第一遍就按终版口径跑**，禁止"先跑再定稿重滚"（本次问1 重滚 3 遍）。
2. **并行拉满矩阵**（用户已裁定精度优先）：
   - 求解层：滚动窗口间无依赖的灵敏度点、EEV、端点、α 对照 → 多进程并行（参考 run_sens 的 --worker 模式），核数=物理核−1；
   - 波次层：硬依赖之外一律同波（问2 可与灵敏度并行；EEV 可与问2 主线并行；评审可与无关章节写作并行）；
   - 层级禁止：主对话亲自写代码/文档超过 15 分钟仍未完成 → 立即改为派 agent。
3. **巡检节拍表**（主对话必须执行，见 §3 分工）：
   - 派单后 T+30min 首查，之后每 30~60min 一查：`ls -lt` 产物时间戳 + 进程 CPU；
   - 连续 2 次检查无新产物 → SendMessage 质询；超任务书时限 → 强制收工令（含"按现状定稿+如实标注未完成项"）；
   - 每次收到完工通知：先跑该 agent 的判据核验脚本再进入下一波。
4. **空窗消灭**：波次间等待通知的时间用于：预写下一波任务书、跑独立支线（图、文献检索、表10 对齐）、或主动巡检。**禁止结束回合干等**。
5. **平台失败预案**：agent 启动即挂（captcha/model request）→ 不重试超过 1 次，主对话拆掉该任务中最重的 30% 自己做，其余重派。

## 3. 主对话 / 子 agent 分工铁律（对标 2025C：主对话仅写 1 个文件）

- **子 agent 承担**：一切代码编写、批量求解、章节写作、绘图执行、评审执行、打包执行。
- **主对话承担**：破题与契约把关、波次编排、任务书撰写、巡检与纠偏、跨 agent 一致性（数字/术语/图号）、发散与备选方案、与用户沟通。
- **主对话写文件仅限**：PROGRESS、all_results 合并、跨 agent 冲突的紧急修复（单点、<15 分钟）。

## 4. 生图升级：复刻获奖卷图式

- **流程**：开赛即把对标获奖卷（references/20 号对应卷 + 对标学习/ 下 PDF 逐页截图）的**每张数据图**拆解为"图型/布局/标注/配色"四要素卡片，构成图式模板库；写图任务书时按数据特征**指定套用哪张卡**，禁止自由发挥基础款。
- **基础款禁用清单**（单独出现即不合格）：裸折线、裸条形、无标注堆叠图、无数值注释热力图。至少叠加：关键点数值标注、参考线/阈值线、双轴（异量纲）、分面板（组图 ≤2）、误差棒/区间带（随机量）。
- 流程图继续按 25 号 SOP（高密度黑白 draw.io，本次图1 是合格样板）。
- 嵌图管线见 §1#3：SVG 源文件 → Edge 2x 截图 PNG（350~420 DPI）→ add_picture；**矢量混合嵌（svgBlip）未经验证，赛前禁用**。

## 5. 文献规则

- **知网首选**：中文期刊/学位论文为主；仅保留方法论开山作 3~5 条外文（如 Rockafellar & Uryasev 2000、Nelsen Copula、Birge & Louveaux）。
- 比赛开赛即检索入库（题面关键词中文检索），写作批次直接引用，禁止临拼。

## 6. 交付终检追加项（并入 14 号流程）

docx 拆包验证：`media 数 == drawing 数 == 图丢失占位 0`；格式校验脚本 0 FAIL；freeze check 零漂移；提交包与附录表 10/11 程序化 diff 一致。

## 5+. 知网检索通道（2026-08-31 实测跑通）

- **入口**：`cumcm.cnki.net`（知网研学平台，竞赛组委会指定）→ 手机号登录一次（用户自助，agent 不碰凭据），cookie 留存于会话。
- **已验证流程**：主页检索框填词 → 自动在新标签打开 x.cnki.net 研学检索（SPA，**必须在结果页页内检索框重搜一次**才出结果）→ 结果表格可结构化提取（题名/作者/来源/发表时间/被引/下载 + ix.cnki.net 全文在线阅读直链）。
- **自动化要点**：主页"检索"链接有 2 个（1 隐藏），按快照相邻序取第一个；结果页整页刷新会丢检索词；抓取用 domSnapshot 按 `- row "N 题名 作者 来源 时间 类型 被引 下载"` 行正则提取。
- **检索样例与中文文献清单**：`C题_作战/2024C模拟/文献检索_知网实测_2026-08-31.md`（75 条命中，首页 20 条题录+5 条候选引用）。
- **附带资源**：平台内含历年参赛作品（2016~2024 分年树）与 2025 赛题 PDF 直链——"复刻获奖卷图式"的素材源优先走这里。

### §5++.1 合规边界（2026-08-31 追加，文献检索红线）
- **允许**：用户本人登录（人工过验证码）后，低频检索（人工量级）、提取题录元数据用于参考文献、按需单篇在线阅读全文；
- **禁止**：破解/自动化绕过验证码；批量翻页抓取（数据集级搬运）；批量下载或落地存储受版权保护的全文文件；共享账号给自动化脚本高频使用；
- **定性**：人登录+人过验证+辅助浏览自己账号可见内容，与爬虫批量抓取有本质区别；但平台协议可能限制任何自动化辅助，保持"用户主导、agent 辅助记录"的形态，检索频次保持人工量级。

### §5++.2 文献检索人机分工工作流（2026-08-31 用户裁定，正式比赛主路径）

**背景**：实测 agent 驱动知网 SPA 检索耗时长且脆弱（用户裁定弃用为主路径，§5+ 的自动化流程降级为备用/演示）。

**分工**：
- **agent（主对话）出**：按论文章节/方法模块成批给出检索式（每次 5~8 组，格式"主题词+限定（年份/文献类型/期刊层级）"，例："种植结构 AND 多目标优化，2020-2025，学术期刊+硕博"）；收到 PDF 后 24h 内产出**筛选表**（每篇一行：有用/相关/无关 + 一句话理由）+ 下轮检索词建议（通常 1~2 轮收敛）；
- **用户出**：在自己已登录的浏览器检索下载（全文权限在手，几分钟一篇），PDF 放入约定目录 `C题_作战/文献PDF/`，文件名随意（agent 自行识别）。

**agent 侧红线**：不再自动化操作知网页面（登录后页面浏览、人工复制粘贴除外）；批量下载、验证码、全文版权边界见 §5++.1。

**agent 收到 PDF 后的标准动作**：解析题录 → 分类筛选表 → 摘录可引用观点/方法/数据（注明页码）→ 生成 GB/T 7714 引用条目 → 建议下一轮检索词。
