## 执行步骤

### 0.5 代码纪律（对应 123 条 12–14 / 27–30 / 37，必守）
- **预处理四步必做满**（第12–14条）：缺失/异常/重复值全处理并有说明；不同量纲必须标准化/归一化并标注方法；大样本一律代码批量处理，不手动算（第37条）。
- **注释与可复现**（第27–28条）：核心代码全程加注释、关键步骤标清；固定随机种子后**复跑 2 次以上结果一致**才算通过。
- **数据来源**（第30条）：公开数据给出处、模拟数据说明生成逻辑，写进日志头部。
- **不用来源不明的黑箱代码**（第29条）：第三方片段必须可读可解释，否则自己重写。

### 1. 搭代码骨架（对齐实验计划）
- 严格按 `03` 的"运行顺序"里程碑 M0(冒烟)→M1(基线)→M2(主结果)→M3(灵敏度) 组织脚本。
- 每个实验块 = 一个函数/段落，函数名对应块号（`run_block1()` …）。
- **固定随机种子**；数据读入先打印 `shape`、前 5 行、字段含义，确认读对了再算。

### 2. 数据预处理（门 1，不过则停；C题类必做满四步）
**顺序主线（22 号 §8）**：清洗（缺失、异常、重复）→ 缺失填补（回归填补、插值）→ 特征选择/特征构建 → 标准化/归一化。
按"整合 → 分析 → 异常 → 无关"四步，参照国奖 C题 论文做法：
- **整合**：多表自然连接(NJ)、变量处理（时间序列/One-hot）、按日/周/月/年聚合。
- **分析**：探查分布、分类规则（如常年/季节/时令）、同货异源、打折退货，结合领域知识验证。
- **异常**：3σ 法则、业务越界（如利润率>2 剔除）、缺失填充；记录删改条数。
- **无关**：剔除无周期/极低销量的噪声单品（如销售天数<10 且销量<阈值）。
输出"数据清洗摘要"：行数变化、每步动作，写进日志。

### 2.5 按题型专项纪律（2026-08-28 新增，细则以 22 号对应章节为准）
- **相关/回归类**：先做正态性检验选系数（JB >30 样本 / SW <50 样本；正态 Pearson、非正态 Spearman）；相关矩阵带星号显著性标注；禁用灰色关联（不显正负）与回归代替相关分析（共线性）；成分数据先对数比变换。
- **评价类**：正向化/负向化 → 归一化（正向化后必再归一化，防信息丢失）→ 赋权 → 合成；AHP 必过 CR<0.1；多方法排名一致性（Kendall's W / Spearman）入 JSON；禁神经网络打分。
- **聚类类**：先标准化（否则量纲主导距离）；类数三法（肘部/轮廓/AIC-BIC）结果入 JSON；换随机种子、换距离度量重跑验稳定性；报轮廓系数/DBI/CH。
- **分类类**：划分 60/20/20 或 70/30 或 80/20；K 折交叉验证；网格/随机搜索调参全程记录；不平衡数据禁只报准确率，报 F1/AUC/召回 + 阈值依据。
- **时序预测类**：按时间顺序划分（禁随机打乱）；交叉验证用时间分块（滑动/扩大窗口）；特征工程三件（时间特征/滞后特征/外部特征）；ARIMA 走六步（ADF→差分定 d→ACF/PACF+AIC/BIC 定 p q→Ljung-Box 白噪声→预测→报 R²/p/SSE/MSE/MAPE/MAE/RMSE）；**需外推禁用树模型**（先趋势分解，树只拟合残差）；统计软件 summary 表不得直接截图进论文，只提炼有用指标。
- **优化类**：先解 LP 松弛得下界；整数解与下界并列，算 gap=(z_IP−z_LP)/z_LP；出可行性逐条核验表（对照 07 的约束清单，跨期/耦合约束重点核）；随机化算法 ≥200 次随机初始化统计分布；多目标出 Pareto 前沿数据点。
- **随机仿真类**：固定并记录随机种子；重复次数 ≥100（写明）；结果报置信区间；给收敛性判据；分布假设先做检验（KS/卡方）。

### 3. 实现求解
- 严格按 `07` 的方程写，**不许"近似掉关键项"而不说明**。
- 每算出一组核心结果，**立刻写入 `all_results.json`**（结构见下方），不攒到最后。
- 需要表格处，同时生成 `TABLE_*.md`（Markdown 三线表源），供 ④ 直接嵌入。
- **精度一致**：正文表与 JSON/Excel 同精度（统一保留 4~6 位小数），不前后不符。
- **基线对照必须落数**：基线与主力模型同指标同表（预测=朴素/漂移修正；优化=LP 下界；评价=等权），JSON 里键名成对（如 `Q2_RF_RMSE` / `Q2_基线_RMSE`）。

### 3.5 风险探针（跑正式实验前，每个候选方法先过五项体检，2026-08-29 新增）
**先探针后大规模实验**：探针用小样本/短迭代快速跑，五项全 PASS 才投入正式求解；有 CONDITIONAL 项记录阈值与实测值后再放行。产出 `results/Qx/probes/risk_probe_summary.json`（或简表进 RESULTS_qX.md）：
1. **可执行**：冒烟跑通无异常，记录运行时长量级；
2. **数据覆盖**：实际用到的行数/有效样本量/缺失率（覆盖不足=结论不稳）；
3. **假设检查**：逐项带阈值给实测值（如多重共线性 max_vif<10、ARIMA 平稳性检验、残差正态性）；
4. **输出退化**（聚类/分类/优化暗雷）：唯一输出数、输出变异系数、top-k 结果集中度——检测"聚了三类其实全在一类""优化器永远返回同一个点"这类隐蔽失败；
5. **小扰动敏感 + 规模**：权重/关键参数 ±5% 扰动结果不翻转；最大数据规模跑通不超时。
（改编自 MathModeling-skills 的 risk-probe-contract；与 21 号 §8 自查三句话互补：那里管选型方向，这里管方法在**本题数据上**能不能站住。）

### 4. 七类自检（质量门，全过才交付）
逐条跑，命中即修，见文末"自检清单"。

### 5. 出图（**SVG 矢量优先，对标 C050 密图 + 17 §5**）
- 轴标/图例**全中文**（守 `04` 第 4 条），只保留变量符号与 SI 单位英文。
- 存 `figures/`，**优先 `.svg` 矢量图**（黑白极简、信息密度高、`build_docx.py` 直接嵌入不糊）；确需位图时用 300dpi `png`。
- 图题（进 Word 时在**下**）≤15 中文字、无公式，公式放正文（守 `04` 第 3 条）。
- **密图**：每个子问题章至少 1~2 张；禁"AI 一眼看出"的通用条形/折线，图型按数据特征多样化（箱线/热力/等高线/双轴/置信带/QQ/残差……见 23 号 §2）；**组图最多 2 个子图**且仅在一张图说不清时用（(a)(b) 标注），单图单插不堆砌，禁止默认样式裸图。

### 5.5 数据侧写素材（供 五、数据侧写）

- [ ] **收敛稳定**：迭代收敛；无 Inf/NaN；同一输入多次跑结果一致
