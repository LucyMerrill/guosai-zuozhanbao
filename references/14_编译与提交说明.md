# 编译与提交说明（论文.md → 国赛 Word 原模板 .docx → PDF）

> 对应 SOP 第 ⑥ 阶段。④ 产出 `论文.md` → `build_docx.py` 转套 `17` 规范的 `.docx` →
> `validate_docx_format.py` 程序化核验 → Word 导出 PDF。
> **cumcmthesis LaTeX 路线降为备选**（见第六节），主路线是用户指定的「国赛 Word 原模板」。

---

## 一、为什么走 Word 原模板路线（主）
- 用户给的「国赛论文模版（最强版）.docx」= 2023 国一 C050 范本，**评委最熟悉、格式最"像国一"**。
- 全部格式规范已固化进 `17_国赛Word原模板格式规范.md`，并由 `validate_docx_format.py` 实测核验，不靠记忆。
- `build_docx.py` 把 `论文.md` 自动套用（v3 口径，对齐 17 号 §2A）：正文宋体**小四 12pt** 单倍行距、黑体标题、三线表（**显式加边框**）、图题下/表题上、首页题名+摘要直接开篇（无封面信息表）。
- 可在 agent 沙箱直接跑（python-docx 不依赖 CJK 字体加载），**不像 xelatex 会被杀**。

## 二、主路线怎么用（比赛当天）
1. 把 ④ 产出的 `论文.md` 与 `figures/`、`TABLE_*.md` 放在同目录。
2. 运行（沙箱或本机均可）：
   ```
   python build_docx.py 论文.md --out 论文.docx --template "国赛论文模版（最强版）.docx"
   ```
3. 程序化核验（**fail==0 才过**，否则逐条改）：
   ```
   python validate_docx_format.py 论文.docx --json check.json
   ```
4. 用 Word 打开 `论文.docx` 微调（封面信息表填真实信息）→ 导出 PDF。

## 三、论文.md 写作的硬规则（决定转 docx 成败）
- **章节**：`# 一、问题重述`→H1，`## （一）…`→H2，`### …`→H3；中文序号、不自动编号。
- **编号公式**：写 `$$ ... $$`（或 `$$\tag{n}$$`），`build_docx.py` 转 Word 公式/高保真图，正文引用用 `式(1)`。
- **图**：`![图 1 销售量季节性波动](figures/fig1.svg)`，图题在**下**，自动取括号前"图 N …"作题。
- **三线表**：用 Markdown 表，首行表头；`build_docx.py` 转时加三线边框（顶/底粗、表头下细、无竖线），表题在**上**。
- **参考文献**：`[1] 作者.题名[类型].刊名,年,卷(期):页码.`，`build_docx.py` 识别 `[n]` 行。
- **数字**：全部来自 `all_results.json`，不手编；表直接嵌 `TABLE_*.md`。

## 四、封面信息表（全框，模板未含需补）
- （v3 已移除）旧版在摘要页前插全框信息表——现按 C050 范式**无封面信息表**，校验器反查“不得出现”。
- 提交前填真实信息；脱敏按赛事要求处理（见第五节）。

## 五、提交前终检（123 条 #116~123）
1. `validate_docx_format.py` 跑通：`fail==0`；`warn` 仅允许"封面/图表类"且已处理。
2. 通读无乱码/无空白页/图清晰、矢量图不糊。
3. 全篇搜学校名、队员姓名、队号，确认已删除（脱敏）。
4. 按赛事命名（如 `队伍编号.docx/.pdf`）；承诺书单独签字上传，**不塞进论文**。
5. **至少提前 1 小时提交**，提交后确认文件可打开。

## 六、备选：cumcmthesis LaTeX 路线（仅当 Word 路线不可用）
- 若需 LaTeX 排版：Pandoc 套 `build/` 下官方 `cumcmthesis.cls`，xelatex 编译。
- **限制**：xelatex 在 agent 沙箱会因 CJK 字体加载被杀；旧 `build/build.bat` 目录已废弃，如走 LaTeX 备选须在本机用 scripts/cumcmthesis.cls 手动编译。
- 编号公式用 `\begin{equation}\label{}`；图 `![..](#fig:x)`；Pandoc 3.7 不支持 `{#eq:x}`/`{#tbl:x}`。
- 主路线已改为 Word，**LaTeX 仅作兜底**，不再默认。

## 附：docx 终检三指标（2026-08-31 新增，详见 27 号 §6）
编译后必须拆包验证：`media 数 == drawing 数 == 图丢失占位 0`（python-docx 不支持 SVG，嵌图一律先用 Edge 无头 2x 截图转 PNG）；validate_docx_format 0 FAIL；freeze check 零漂移；提交包与附录表 10/11 程序化 diff 一致。
