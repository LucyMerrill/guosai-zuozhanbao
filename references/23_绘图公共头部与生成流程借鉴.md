## 1. 绘图公共头部（每个求解脚本强制粘贴）

解决四件事：Windows 中文乱码、无人值守无窗口渲染、中文字体回退、SVG+300dpi 落盘出口（对齐 09/10 号与 build_docx.py 标准）。

```python
# ── 绘图公共头部：紧跟 import 之后 ──
import sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')  # Windows 打印中文防乱码，必须前两行

import matplotlib
matplotlib.use('Agg')                        # 无窗口后端，无人值守必需
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei', 'SimSun']  # 中文字体回退链
plt.rcParams['axes.unicode_minus'] = False   # 修负号渲染成方块
plt.rcParams['figure.dpi'] = 110             # 仅屏显预览
plt.rcParams['savefig.dpi'] = 300            # 落盘分辨率
plt.rcParams['savefig.bbox'] = 'tight'
plt.rcParams['axes.grid'] = True
plt.rcParams['grid.alpha'] = 0.3
plt.rcParams['grid.linestyle'] = '--'

def despine(ax):
    """去上/右边框，评审普遍好感"""
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)

def save_fig(fig, name):
    """统一出口：SVG+PNG 双份，杜绝漏存/漏关；name 形如 '图1_各城市月均气温'"""
    fig.savefig(f'figures/{name}.svg')           # 矢量，Word 嵌入不糊
    fig.savefig(f'figures/{name}.png', dpi=300)  # 位图兜底
    plt.close(fig)
```

## 2. 生图细节铁律（配合公共头部使用）

| 规则 | 写法 | 为什么 |
|------|------|--------|
| **图内禁画标题** | 不调用 `set_title()`，标题由图题（caption）承担 | 避免图内+图题重复两遍，AI 生成论文的高发扣分点 |
| 多系列取色 | `plt.cm.viridis(np.linspace(0.1, 0.9, n))`（渐变）或 `plt.cm.tab10/Set2`（分类），全文固定一种 | 任意系列数颜色都协调，天然满足自查 100 条"配色统一" |
| 折线 | 线宽 ≥1.5 + 标记点 | 投影/打印后仍可分辨 |
| 柱状 | `edgecolor='white', linewidth=0.5` | 白边分隔，立刻"干净" |
| 散点 | `alpha=0.7, edgecolors='black', linewidth=0.5` | 密集点不糊团 |
| **含中文字符串用双引号** | `df["婴儿行为特征"] = "矛盾型"`，严禁写成 `'\u5a74\u513f...'` 转义序列 | 防 Unicode 转义把中文变乱码（MathModelAgent 踩坑）；双引号也避免单引号转义 |
| 图内元素白名单 | 只有：数据、轴标签刻度、图例（全中文） | 对齐 10 号"信息密度高、无装饰" |
| 每问图量基准 | 至少 4~6 张覆盖主要分析维度 | 对齐 10 号"密图：每子问 1~2 张" |
| **单图单插** | 每张图独立编号、独立图注、随文插在首次引用处；同一分析点默认 1 张图说清，确实不够才加到 2 张 | 严禁五六张图拼成一大块堆在一处，评审抓不到重点（用户 2026-08-29 明确要求） |
| **组图上限 2** | 仅当一张图确实描述不清才拼组图，且最多 (a)(b) 两个子图；能用一张说清就用一张 | 同上；组图是例外不是常态 |
| **图型多样化** | 按数据特征选型：箱线/小提琴/热力/等高线/双轴/误差条/置信带/QQ/残差/阶梯/边际分布……不只折线柱状散点老三样 | 用户原话"图片形式要多样化，不要总是最基础的那几样"；以表达更清楚为前提，不为花而花 |
| **美观不偷懒** | 禁止裸用 matplotlib 默认样式入稿（默认配色/网格/字号直接出图=偷懒）；按本表逐项打磨 | 用户原话"生成图要美观，不要偷懒" |

## 2.5 成图验收（render check：查渲染成品，不只查代码，2026-08-29 新增）

每张图写入 FIGURE_MANIFEST 前对着**导出的 PNG/SVG 成品**逐条过（改编自 MathModeling-skills render-check；流程图另走 25 号 judge 验收）：

- [ ] 无裁切：标题位（图题在 caption）、轴标签、刻度、图例、标注、colorbar 都完整在画布内；
- [ ] 无标注重叠遮挡数据；最终排版尺寸下字号仍可读（想象缩进 Word 双栏/缩印后）；
- [ ] 单位、排序、刻度范围、类别标签正确，与数据一致；
- [ ] 无空白子图或误留的空坐标轴；
- [ ] 灰度打印与常见色觉缺陷下，系列仍可分辨（靠线型/标记点兜底，不只靠颜色）；
- [ ] 置信带、基线、主模型在图例中标识正确、身份不混；
- [ ] 图与图注支撑**同一条结论**（图注说的事，图里看得出来）；
- [ ] 图的数据来源行数/口径与 `all_results.json`（或 data_audit）一致——对不上=用了旧图；
- [ ] 输出文件确实存在于 `figures/`（svg+png 双份），非陈旧缓存。

## 3. 流程图固定模板（Word 管线适配版）

Mrite 原法：TikZ 九框固定坐标，AI 只许改框内文字（每框≤7字），坐标箭头一字不动——保证永不编译失败、永不出现"死亡图"。本包 Word 管线等价实现：matplotlib 固定 3×3 S 形走线函数，同样**只换文字不改布局**：

```python
import matplotlib.patches as mpatches

def draw_flow(labels9, fname='图N_问题X分析流程图'):
    """固定 3×3 S 形流程图。labels9：9 个 ≤7 字标签，
    填充顺序：左上→右上，右下→左下（中行），左下→右下。
    布局与箭头固定只换文字；箭头走框边不穿框。"""
    W, H, GX, GY = 2.6, 0.9, 3.2, 1.5      # 框宽/框高/列距/行距
    fig, ax = plt.subplots(figsize=(7.5, 3.4))
    P = {(r, c): (c * GX, -r * GY) for r in range(3) for c in range(3)}
    for (r, c), (x, y) in P.items():
        ax.add_patch(mpatches.FancyBboxPatch((x - W/2, y - H/2), W, H,
                     boxstyle='round,pad=0.06', fc='#eef3f8', ec='#4472c4', lw=1.2))
        ax.text(x, y, labels9[r * 3 + c], ha='center', va='center', fontsize=11)
    for a, b in [((0,0),(0,1)), ((0,1),(0,2)), ((0,2),(1,2)), ((1,2),(1,1)),
                 ((1,1),(1,0)), ((1,0),(2,0)), ((2,0),(2,1)), ((2,1),(2,2))]:
        (xa, ya), (xb, yb) = P[a], P[b]
        if ya == yb:  # 水平箭头：按走向接框边（S 形中行是右→左）
            if xb > xa: start, end = (xa + W/2 + 0.06, ya), (xb - W/2 - 0.06, yb)
            else:       start, end = (xa - W/2 - 0.06, ya), (xb + W/2 + 0.06, yb)
        else:         # 垂直箭头：上框底边 → 下框顶边
            start, end = (xa, ya - H/2 - 0.06), (xb, yb + H/2 + 0.06)
        ax.annotate('', xy=end, xytext=start,
                    arrowprops=dict(arrowstyle='-|>', color='#4472c4', lw=1.4,
                                    shrinkA=0, shrinkB=0))
    ax.set_xlim(-1.8, 7.9); ax.set_ylim(-3.6, 0.9); ax.axis('off')
    save_fig(fig, fname)
```
