# 22 · 题型流程化解题手册（七类高频题的完整作业流程）

> 来源：《数学建模流程化解题思路》全文精读蒸馏（2026-08）。
> 地位：**阶段③ 代码求解、阶段② 方法细节的第一参考**。与 21 号（判型选型）配对：21 号解决"这问是什么任务、选哪个模型族"，本文件解决"选定之后，每一步做什么、报什么数、躲什么坑"。
> 通用主线：**数据预处理（清洗→填补→特征选择/构建→标准化归一化）→ 建模 → 求解 → 检验必报量 → 图表呈现**。所有数字进 `all_results.json`（09 号规则）。

## 1. 相关性分析（关联类题第一步）

**数据处理**：收集（样本数量合理）→ 清洗（缺失/异常/重复）→ 特征选择（去无关冗余）→ 特征转换（独热编码、归一化/标准化）。

**流程五步**：
1. **判断数据分布是否正态**：Jarque-Bera 检验（样本 >30）、Shapiro-Wilk 检验（样本 <50 更优）、Q-Q 图可视化辅助。
2. **按分布选系数**：正态 → **Pearson**；非正态 → **Spearman**。
3. **混合情形**（有的特征正态有的非正态）：按**大部分特征**的情况选；或改用 Kendall（适合非正态，但大数据量时计算效率不高）；必要时考虑典型相关分析。
4. **显著性标注**：p 值 + 显著性水平 0.05；相关矩阵加**星号标注**（*** p<0.01, ** p<0.05, * p<0.1）或颜色突出显著项。
5. **解读**：结合业务解释正/负相关与强弱，与可视化（散点、热力图）互证。

**不推荐清单（评委视角）**：
- ❌ **灰色关联分析**——概念模糊且**不能显示正负方向**（除非题面点名要求）。
- ❌ **用回归/树模型特征重要性代替相关性分析**——存在多重共线性干扰；若确要做回归，先诊断共线性并用**岭回归（L2）**处理。
- 成分数据（各比例和为定值，如化学成分）：直接算相关是错的，需对数比变换（21 号 §2.3）。
- 分类变量之间：用**卡方检验 + Cramer's V**，不用 Pearson（见 10 号卡方范本）。

## 2. 综合评价类完整流程

**数据处理**：
1. 清洗（缺失/异常）；
2. **正向化/负向化**：指标方向不一致时统一方向（极大化、极小化、百分比转化等；效益型/成本型公式见 21 号 §2.4）；
3. **归一化/标准化**：统一量纲——注意：模型对量纲不敏感或指标无需量纲一致时可省；**极大/极小化处理后应进一步归一化，保证各指标对结果影响均衡**（否则信息丢失）；
4. **指标赋权**：AHP（主观，**无数据时**才用）、熵值法（客观，数据量大时用）、CRITIC/变异系数（客观）。

**模型选择**：
| 模型 | 适用 |
|---|---|
| 加权求和 | 结构简单、权重已知 |
| TOPSIS | 与理想解/负理想解距离排序，最常用主力 |
| AHP | 多层次指标、结合主观因素；**必须过一致性检验**（CR<0.1，不过则重调判断矩阵） |
| 熵值法 | 需客观赋权、数据量较大 |
| ❌ 机器学习自动评价（SVM/树/神经网络打分） | **国赛不推荐**——忽视解释性与透明度，评委无法核验（21 号 §8） |

**验证方法（五件套，至少做 2、最好全做）**：
1. **一致性检验**（AHP 专属）：算 CI、CR，CR < 0.1 才通过；
2. **敏感性/稳定性分析**：调整权重或评分标准，观察排名是否显著变化；
3. **多方法对比**：同数据上跑 TOPSIS + 熵权 + 加权求和，比较结果相似度（报 Spearman 相关系数/Kendall's W 一致性系数，越接近 1 越稳定）——但注意 21 号实证：赋权法之间排名几乎不变（0.9762），**论文重心放在指标方向与量纲的论证上，赋权法论证 ≤3 行**；
4. **合理性/解释性验证**：与专家打分/实际场景对照，算模型结果与专家排名的相关性；
5. **重抽样验证**：分组验证或 Bootstrap 重抽样，统计多次评价结果的方差（方差小 = 稳定）。

## 3. 聚类类完整流程

**前置**：收集 → 清洗 → 特征选择 → 编码/归一化（**不标准化直接聚类 = 量纲大的指标主导距离，必错**）。

**五族聚类选择表**：
| 族 | 代表 | 适用 | 需预指定 K？ | 类数/效果确定 |
|---|---|---|---|---|
| 基于中心（距离） | K-Means、K-Medoids | 大数据集、紧密球状簇 | **是** | 肘部法、轮廓系数 |
| 基于密度 | DBSCAN、OPTICS | 含噪声、簇形状不规则非球形 | **否**（半径 ε+MinPts 自动定） | 轮廓系数、ARI；调 ε 与 MinPts |
| 层次聚类 | 凝聚/分裂 | 数据量适中、要层次结构（如生物分类） | 否（树状图自行截断） | 树状图选截断点；轮廓系数、DBI |
| 概率模型 | GMM 高斯混合 | 簇重叠、要软分配概率 | 是 | **AIC/BIC** 最小者 |
| 基于图 | 谱聚类 | 复杂分布、流形结构、非凸簇 | 是 | 轮廓系数、DBI |

**确定 K 三法**（适用于需指定 K 的模型）：肘部法（SSE 拐点）、轮廓系数（最高者）、AIC/BIC（GMM）。**类数必须给依据，不许拍脑袋**（21 号 §2.6）。

**效果评估三组指标**：
- 内部：轮廓系数（越高越好）、DBI（越小越好）、CH 指数（越大越好）；
- 外部（有真标签时）：ARI ∈ [−1,1]（1 完全一致）、NMI（接近 1 好）；
- 可视化：PCA/t-SNE 降维散点、层次聚类树状图。

**注意**：聚类结果必须做**稳定性检验**（换随机种子、换距离度量重跑）；**不可把聚类标签当真实类别算准确率**；K-Means++ 初始化可写为小创新点（C050 用它划分热销/非热销产品即为数据侧写创新）。

## 4. 判别分类类完整流程

**前置**：收集（类别分布合理）→ 清洗 → 特征选择 → 编码/归一化 → **数据集划分**：训练/验证/测试 = 60/20/20 或 70/30 或 80/20。

**模型选择条件表**：
| 数据情形 | 首选 |
|---|---|
| 量小、特征少、线性关系 | 逻辑回归（可解释特征重要性）、SVM、KNN |
| 非线性边界、小样本 | SVM（核技巧升维） |
| 量大、特征多 | 随机森林、梯度提升、神经网络 |
| 有噪声或特征强相关 | 随机森林、梯度提升树 |

**训练要点**：网格/随机搜索调超参（神经网络另加学习率调节、正则化）；**K 折交叉验证**（5 或 10 折）保稳定性；图像/文本可用数据扩增。

**评估指标（二分类，多分类推广）**：
| 指标 | 适用 |
|---|---|
| Accuracy | 类别平衡时 |
| Precision / Recall | 正负不平衡、关注正类（如疾病检测） |
| F1 | 不平衡时的整体调和评价 |
| AUC-ROC | 各阈值下 TPR-FPR，衡量区分能力，越高越好 |

**红线**：类别 9:1 失衡时报准确率 = 指标失效（全判多数类即 90%）；必须报 F1/AUC/召回 + **阈值选择依据** + 交叉验证方式（21 号 §2.5）。方法顺序按 21 号 §2.5：Logistic → LDA/QDA → 树集成 → SVM → 神经网络（样本充足时）。

## 5. 回归预测类完整流程

**数据预处理（预测特有）**：收集 → 清洗（缺失/异常，必要时插值填充）→ **时间特征提取**（年/季度/月/周）→ **滞后特征构造**（历史值作特征）→ **外部特征添加**（天气、假期、经济指标）→ 划分数据集（**时间序列必须按时间顺序划分**，禁随机打乱）。

**模型选择条件表**：
| 数据情形 | 首选 |
|---|---|
| 线性且平稳（短期预测） | ARIMA；有季节性 → SARIMA / Holt-Winters 指数平滑 |
| 复杂非线性关系 | SVR、随机森林、XGBoost |
| 量大且短期依赖复杂 | LSTM、GRU、CNN-LSTM |
| 样本 <50 不外推 | 灰色预测 GM(1,1)、移动平均（与朴素基线同表对比） |

**训练与验证要点**：
- ARIMA 超参用 ACF/PACF 图 + AIC/BIC 选（见 §6）；ML/DL 用网格/随机搜索；
- **时间序列分块交叉验证**（滑动窗口法或扩大窗口法），保证训练集时间早于验证集；
- 特征重要性分析（随机森林 importance 或 **SHAP 值**）筛选关键特征。

**判断模型好坏（六查）**：
1. 多模型**同指标对比**（RMSE、MAE、R²、MAPE）选最优；
2. 泛化能力：验证集与测试集表现接近才算好；
3. **学习曲线**：训练误差低 + 验证误差高 = 过拟合；
4. **误差分布分析**：误差有无明显偏差或趋势（检查稳定性）；
5. 预测精度 + 误差分布均匀；
6. （可选）训练效率与解释性（线性回归可给特征重要性辅助决策）。

**⚠️ 呈现红线**：统计软件的 summary 回归表**不能直接截图**——大部分信息没用，只提炼 p 值、R²、调整 R²、SSE 等有用指标进正文表格。**必须与朴素基线同表对比**（21 号 §2.2：随机森林 RMSE 可能是最优一行公式基线的 2.47 倍）。

## 6. ARIMA 专题六步（时序题优先候选，步骤全、公式全、图全）

适用：平稳时间序列。**先预处理**（缺失/异常不能忘）。

1. **平稳性判断**：ACF/PACF 图目测 + **ADF 检验**（一般用）+ KPSS 检验（辅助）。平稳性 = 均值方差随时间不变。
2. **差分**：不平稳则差分至平稳（一阶不行二阶）；**平稳则 d=0**。差分目的：消除趋势、使均值方差恒定便于拟合。辅助手段：对数变换（减弱波动，适合增长率高的序列）、季节调整。
3. **定 d**：差分几次后平稳，d 就是几（一阶平稳 d=1）；差分次数越少越好（避免过拟合）。
4. **定 p、q**：**PACF 截尾对应 p，ACF 截尾对应 q**（看图快速下降到 0 处，误差不大即可）；同时用 **AIC 或 BIC 准则**（选其一为准，图示法+AIC/BIC 结合定，防误差）。⚠️ 若本次赛题内容已很多，ARIMA 细节从简甚至不选 ARIMA——它本身内容量就大。
5. **白噪声检验（Ljung-Box）**：对残差检验。残差为白噪声 = 模型已充分提取信息、无系统性模式遗留、预测可靠；不是白噪声 → 调整 p、d、q 或加特征。
6. **预测 + 报指标**：R²、p 值、SSE、MSE、**MAPE**、MAE、RMSE。

**创新加分项——混合模型**：ARIMA（捕获线性趋势）+ LSTM/神经网络（捕获剩余非线性残差），串联建模。
**SARIMA(p,d,q)(P,D,Q,m)**：不推荐首选（复杂占篇幅）；确要seasonality 时——D 通常为 1（不超过 2）；m 看周期（月度数据 m=12，日数据年度周期 m=365）；季节性滞后阶处 PACF 截尾定 P、ACF 截尾定 Q；P、Q 也可用 AIC/BIC 确定。

## 7. 规划优化类完整流程

1. **明确问题定义**：目标函数（最小化成本/最大化收益/最短路径；一个或多个目标）；约束条件（资源/时间/容量；等式或不等式）；决策变量（连续/离散/整数/0-1）。
2. **构建数学模型**：目标函数数学化（决策变量的线性/非线性组合）；约束逐条数学表达；变量类型与取值范围（保证解有实际意义）。线性化三招见 21 号 §5。
3. **类型分析**：LP（全线性）/ IP（全整数）/ MIP（混合）/ NLP（含非线性）/ DP（多阶段递推）/ MOP（多目标）。
4. **求解算法选择**：
   - 线性/整数：单纯形（小规模 LP）、内点法（大规模 LP）、分支定界（IP）、割平面；
   - 非线性：梯度下降（凸）、拟牛顿（非凸）、拉格朗日乘子（等式约束）、GA/PSO 等智能优化（复杂非凸）；
   - 动态规划：多阶段决策（最短路、背包）；
   - 多目标：加权和（**仅当权重有依据时**）、Pareto 最优前沿、NSGA-II——**默认给 Pareto 前沿，禁直接线性加权**（21 号 §2.7）。
   - 路线按规模分档（≤10⁵ 精确 / 10⁵~10⁶ 松弛+启发式 / >10⁶ 或黑箱 元启发式），必报 LP 下界与 gap。
5. **结果分析与验证**：可行性核验（解满足全部约束，逐条核对——2024C 评阅逐条查土地/重茬/豆类）；敏感性分析（调参数、约束松弛看解变化）；**算法对比**（不同求解算法/模型对比求解时间、解质量、稳定性）；**多次随机初始化取平均**保稳健；可视化（收敛曲线、Pareto 前沿、解的变化过程）。

## 8. 数据预处理与降维（通用模块）

**预处理主线**：清洗（缺失、异常、重复）→ 缺失填补（回归填补、插值）→ 特征选择/特征构建 → 标准化/归一化。与 09 号"整合→分析→异常→无关"四步配合使用（09 管动作完整性，本节管顺序）。

**降维**：
- 无监督 → **PCA**；有监督（分类场景）→ **LDA**；
- 目的：提高模型效果、减少计算、可视化；
- ⚠️ **降维之后的数据无物理意义**（论文解释时只能回到原始变量载荷）；
- 变相降维 = 特征选择：决策树特征重要性、相关性筛选等。

## 9. 按题型的必做检验速查（与 21 号必报量对接）

| 题型 | 检验动作（写论文时每问"检验"段必含） |
|---|---|
| 相关/回归 | 正态性检验（JB/SW）→ 残差诊断四项 + VIF + 系数 CI + p 值效应量 |
| 评价 | CR<0.1 一致性 + 权重扰动敏感性 + 多方法排名一致性（Kendall's W/Spearman） |
| 聚类 | 轮廓系数/DBI/CH + 类数依据（肘部/轮廓/AIC-BIC）+ 换种子换度量的稳定性 |
| 分类 | 混淆矩阵 + F1/AUC/召回 + 阈值依据 + K 折交叉验证 |
| 预测 | 测试段误差（RMSE/MAE/MAPE）+ 朴素基线对照 + 预测区间 + 外推比例 + 残差白噪声检验（ARIMA） |
| 优化 | 可行性逐条核验表 + LP 下界与 gap + 敏感性（参数±、约束松弛）+ 多次随机初始化 |
| 随机仿真 | 重复次数与种子 + 置信区间 + 收敛判据 + 分布假设检验 |

**总红线**：任何模型的输出都必须**可被评阅人核验**——报不出检验数的模型，要么换模型，要么补检验，不允许"结果良好"式空话收尾。
