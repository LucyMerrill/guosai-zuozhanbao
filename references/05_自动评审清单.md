# 自动评审清单（123 条终检总表 · 打勾版）

> 融合用户提供的「数模竞赛 123 条全流程自查清单」。完整原文见 `12_123条全流程自查清单_原文.md`。
> 用法：**第 ⑤ 评审**我当审稿人按【评】类逐条挑刺；**第 ⑥ 交付前**你拿本表逐条打勾。
> 标记：`[人]`=需你(队长)确认　`[自]`=我写稿/求解时自动守　`[评]`=我当审稿人重点挑刺（融合 `08`）

## 附：八类任务必报量核查（2026-08-28 新增，第 ⑤ 评审按问必查）

> 来源：`21_赛题识别八类任务判据.md`。**先看契约选型总表确定该问任务类型，再按对应行逐项核对；写不出必报量的问 = 类型判错或论证不完整，判"重要"级以上问题。** 题面出现"不确定性/风险/稳健"的问，另查是否补做了灵敏度/稳健性分析（没做 = 分值上限锁死）。

- [ ] 机理建模问：参数估计值与真值/文献值对比、参数可辨识性、量纲一致性、边界条件敏感性
- [ ] 预测问：与朴素基线同表对照、测试段误差（RMSE/MAE/MAPE）、预测区间、外推比例
- [ ] 回归关联问：残差诊断四项、VIF、系数置信区间、p 值与效应量
- [ ] 评价问：指标方向与量纲的依据、赋权法互换排名一致性、方向改判头部保留率
- [ ] 判别问：混淆矩阵、精确率/召回率/F1、AUC、阈值选择依据、交叉验证方式
- [ ] 聚类问：轮廓系数等内部指标、类数选择依据、换种子/换度量的稳定性
- [ ] 优化问：模型完整形式（变量/目标/全部约束）、求解器与耗时、LP 下界与 gap、可行性逐条核验表、解结构稳健性
- [ ] 随机仿真问：重复次数与随机种子、置信区间、收敛性判据、分布假设检验结果
- [ ] 跨问接口：上游预测是否给了区间、下游是否做区间端点对照求解；求解器切换处是否有说明

## 评审 / 终检用法
- **第 ⑤ 评审**：我当审稿人，按【评】类条目逐条挑刺，输出"致命 / 重要 / 润色"三级问题 + 改法；迭代到 **致命=0 且 总分≥85** 才放行（同 `08_技能_auto-review.md`）。
- **第 ⑥ 交付前**：你拿本表逐条打勾——【人】类由你确认，【自】类我在写稿/求解阶段已自动守，【评】类由我终检兜底。
