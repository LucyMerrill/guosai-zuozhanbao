# 21 · 赛题识别与模型选型：八类任务判据（破题圣经）

> 来源：《第一讲 赛题识别与模型选型》技能总结课（2026-08 精读蒸馏，全文知识已消化）。
> 地位：**阶段① 破题、阶段② 选型的第一裁决文件**。判定分三层：题面要求的输出定任务类型 → 三处二次判定（是否外推 / 机理是否已知 / 有无标签）定分支 → 方法族最后才由数据条件确定。
> 两条纪律：**先判"要什么"，再判"用什么"**（跳过第一步直接想模型是选型失败最常见起点）；**按问判定，不按题判定**（2023 C 三问分别落在关联 / 预测+决策 / 决策，给整道题贴一个"数据分析题"标签，第三问必然做错）。

## 1. 开赛后 40 分钟操作流程（三人分工，逐分钟执行）

| 时段 | 动作 | 产出 | 由谁做 |
|---|---|---|---|
| 0–10 min | 通读全部题目，逐问画出**设问动词**，先不看数据 | 每问一个任务类型标签 | 三人各读一题后交叉复述 |
| 10–20 min | 数据体检：样本量、缺失、量纲、时间跨度、类别是否失衡、有无标签 | 一页数据概况表 | 编程手 |
| 20–30 min | 写变量下标与约束草表，暂不写公式细节 | 决策变量定义与约束条目 | 建模手 |
| 30–40 min | 定方法链，跑一个**最小算例**确认求解器不报错 | 可运行的骨架代码 | 编程手+建模手 |

**40 分钟只要求拿到一样东西：一张「第几问 → 什么任务 → 什么方法 → 用什么求解」的表。** 写不出这张表 = 题意未把握，此时开始编码必然返工。

三问自检（有一个答不上来就不进下一阶段）：
1. 每一问的任务类型，三人独立判定是否一致？
2. 候选方法里有没有一个**跑得通的简单基线**？
3. 求解器在最小算例上是否已经返回过一次可行解？

## 2. 八类任务完整判据表（本文件核心）

> 每类五件事：题面长什么样 / 关键词 / 方法族按什么顺序取 / **必报量**（写不出必报量 = 类型判错了）/ 常见错法。

### 2.1 机理建模类
- **题面特征**：给物理、化学、几何或工程背景，要求解释现象、推导关系式或反演参数；通常给少量实验数据加一段过程描述。
- **关键词**：传热、传质、扩散、反应速率、受力、遮蔽、干涉、衰减、守恒、平衡、运动轨迹、几何关系、机理、原理、推导、验证…的合理性。
- **数据特征**：样本量小（几十到几百），变量有明确物理单位，存在已知支配方程或几何约束。
- **方法族**：常微分/偏微分方程（差分、有限元）→ 几何解析推导 → 参数反演（非线性最小二乘、遗传算法辅助标定）→ 数值仿真。
- **必报量**：参数估计值与真值/文献值对比、参数可辨识性、量纲一致性检验、边界条件敏感性。
- **真题落点**：2018A 高温作业服装（一维热传导）、2023B 多波束测线（几何覆盖）、2025A 烟幕干扰弹（遮蔽几何+投放时序优化）、2025B 碳化硅外延层（光学干涉反演）。
- **常见错法**：放弃机理改用回归拟合曲线——内插看不出问题，外推立刻失效，参数解释不了。**实证**：牛顿冷却数据上，拟合段机理模型与三次多项式 RMSE 0.32℃ vs 0.31℃ 几乎不可分；外推段相差 **5.5 倍**（0.41 vs 2.27℃）；外推到 90min，机理收敛到 23.2℃（环境温度），多项式给 −35.7℃（物理不可能）。机理模型还多给**可解释参数**（反演冷却系数 0.0454 vs 真值 0.045 min⁻¹）。

### 2.2 预测类
- **题面特征**：要求给出未来某时刻/时段的数值，时间是显式变量。
- **关键词**：预测、预估、预计、未来、第 t+k 期、下一周、趋势、增长率、走势、外推、演化。
- **数据特征**：时间序列，可能含季节性、节假日效应、结构断点。
- **方法族**：先判外推。需外推 → 参数化趋势 / ARIMA / 结构时序模型 / 机理外推；不外推且样本足 → 随机森林、梯度提升、神经网络；样本少 → 灰色预测 GM(1,1)、指数平滑。
- **必报量**：与朴素基线的对照（Skill）、测试段误差、预测区间、外推比例。
- **真题落点**：2023C 第二问（未来一周销量）、2019C（需求量估计）。
- **常见错法**：需要外推时单独用树模型；不划分训练/测试段直接报拟合优度。

**外推判据（量化）**：统计测试段目标值落在训练段 [min, max] 之外的样本比例，**超过 10% 即视为需要外推**。与样本量交叉得四格：

| | 样本量 < 50 | 样本量 ≥ 50 |
|---|---|---|
| **需外推** | 参数化趋势（线性/对数/逻辑斯蒂）、ARIMA 与结构时序；结构假设须单独检验 | 先做趋势分解，**对残差**用机器学习；直接用树模型必然失效 |
| **不外推** | 灰色预测 GM(1,1)、简单指数平滑与移动平均；须与朴素基线同表对比 | 随机森林/XGBoost/LightGBM，样本充足可用神经网络；交叉验证须按时间切分 |

顺序不可颠倒：样本量决定模型复杂度上限，是否外推决定模型族是否成立。

**外推失效的机理（必须写进论文的事实）**：回归树预测值 = 叶节点内训练样本目标均值，恒满足 min(y) ≤ ŷ ≤ max(y)；随机森林/梯度提升是回归树的加权平均，同样被训练段极值**锁死天花板**——与树深、树数、学习率无关，调参调不出上界。Box–Jenkins 航空客流实证（测试段 27.8% 月份超训练段最大值 467）：随机森林测试段预测最大值仅 453.5，RMSE 55.2 = 漂移修正基线（一行公式，零参数）22.4 的 **2.47 倍**。注意：参数化模型能外推 ≠ 外推得对（对数线性外推方向由结构假设决定，该例系统性高估 +56.9），结构假设是否成立要另外检验。

### 2.3 回归与关联类
- **题面特征**：要求给出变量之间关系、影响程度或显著性，**不涉及时间外推**。
- **关键词**：关系、影响、相关、显著性、贡献、解释、依赖、分布规律、相互作用、主要因素、敏感因素。
- **数据特征**：截面或面板数据，自变量与因变量在同一分布内取值。
- **方法族**：描述统计与分布拟合 → 相关分析（Pearson/Spearman/Kendall，按分布选，详见 22 号 §1）→ 多元回归（含交互项、多重共线性诊断）→ 方差分析与假设检验 → 结构方程/路径分析。
- **必报量**：残差诊断四项、方差膨胀因子 VIF、系数置信区间、检验 p 值与效应量。
- **真题落点**：2021B（催化剂组合对收率影响）、2023C 第一问（品类与单品销量关系）、2022C（成分与类型关系）。
- **常见错法**：变量非正态仍用 Pearson；把 R² 高当作模型正确；成分数据（和为定值，如化学成分比例）不做对数比变换直接算相关。

**与预测类的分界只有一条**：目标值是否落在训练数据取值范围内。同一份数据，问"哪些因素影响收率"是回归（看残差与共线性），问"下个月收率是多少"是预测（看测试段误差与外推比例）。

### 2.4 评价类
- **题面特征**：对若干对象排序、打分或分级，题面通常不给"正确答案"。
- **关键词**：评价、评估、排序、排名、分级、优选、综合、指标体系、权重、优劣、竞争力、协调度、贡献度。
- **数据特征**：多对象多指标矩阵，指标量纲不一、方向有正有负。
- **方法族**：指标正向化与无量纲化 → 赋权（熵权、CRITIC、变异系数、层次分析）→ 合成（加权和、TOPSIS、灰色关联）→ 分级（自然断点、聚类）。
- **必报量**：**指标方向与量纲的依据**、赋权法互换后的排名一致性、方向改判后的头部保留率。
- **真题落点**：2020C（信誉等级评价）、2019C 第三问（方案评价）。
- **常见错法**：把篇幅全花在论证赋权法；指标方向判反；正向化方式与指标含义不匹配。

**得分点实证（wine 数据，n=178）**：熵权/CRITIC/等权四套赋权法给出的权重肉眼可见不同（苹果酸 0.123 vs 0.077，差 60%），但四套排名 Spearman 一致性**最低也有 0.9762**——四张榜几乎重合。反过来，只把"色泽强度"由效益型改判为成本型（其余全不动），178 个样本中 **96.6% 名次变动**，平均变动 12.89 名，前十只保住 8 个，榜首换人。
→ **结论：论证"为什么选熵权法"不值得写超过三行；指标方向与量纲的论证才是这类题的得分点。**
- 正向化二选一：z = (x−min)/(max−min)（效益型）；z = (max−x)/(max−min)（成本型）。
- 熵权法：p_ij = z_ij/Σᵢz_ij，e_j = −(1/ln n)Σᵢ p_ij ln p_ij，w_j = (1−e_j)/Σₖ(1−eₖ)。
- CRITIC：C_j = σ_j·Σₖ(1−r_jk)，w_j = C_j/ΣₖCₖ——同时考虑离散程度与指标间冲突性（其余同 22 号 §2）。

### 2.5 判别分类类
- **题面特征**：把对象归入若干**已定义**类别，题面或附件给出带标签样本。
- **关键词**：判别、识别、鉴别、分类、判定、归属、是否、属于哪一类、诊断、检测、预警。
- **数据特征**：有标签，类别数已知，可能类别失衡。
- **方法族**：Logistic 回归 → 线性/二次判别分析 → 决策树、随机森林、梯度提升 → 支持向量机 → 神经网络（样本充足时）。
- **必报量**：混淆矩阵、精确率、召回率、F1、AUC、**阈值选择依据**、交叉验证方式。
- **真题落点**：2022C 第三问（未知玻璃类型鉴别）、2024B（抽样检验判定）、2025C（胎儿异常判定）。
- **常见错法**：类别失衡时报准确率；不说明阈值如何选出；用全部数据训练后报训练集指标。

### 2.6 聚类类
- **题面特征**：把对象分组，题面**没有**给出组的定义，也没有标签。
- **关键词**：分类（无标签语境）、划分、分组、亚类、模式、群体、类型划分、细分、归纳出几种。
- **数据特征**：无标签，类别数未知，需自行确定并论证。
- **方法族**：数据标准化 → K 均值、层次聚类、DBSCAN、高斯混合 → 类数确定（肘部法、轮廓系数、间隔统计量）→ 类的解释与命名（五族如何选详见 22 号 §3）。
- **必报量**：轮廓系数或类内类间距离、**类数选择依据**、聚类稳定性（换随机种子、换距离度量）。
- **真题落点**：2022C 第二问（玻璃亚类划分）、2020C（企业分群）、2025C（按 BMI 对孕妇分组）。
- **常见错法**：不标准化直接聚类（量纲大的指标主导距离）；类数拍定不给依据；把聚类结果当真实类别去算准确率。

**一句判据**：题面出现"已知分为三类，请判断新样本属于哪一类"= 判别（报混淆矩阵）；"请将这些样本划分为若干类" = 聚类（报轮廓系数）。两者不可互换。

### 2.7 规划优化类
- **题面特征**：要求给出可执行的方案、配置或取值，同时给出目标与约束。
- **关键词**：最大、最小、最优、最少、方案、策略、计划、安排、调度、分配、选址、路径、如何设计、约束、不得超过、至少、限制在。
- **数据特征**：决策变量可枚举，约束可写成不等式，参数由前几问给出或题面直接给定。
- **方法族**：线性规划 → 整数/混合整数规划 → 非线性规划 → 动态规划 → 多目标（Pareto 前沿、ε-约束）→ 元启发式（**仅**在规模或黑箱条件下）。
- **必报量**：模型的完整形式（变量、目标、全部约束）、求解器与耗时、**LP 下界与 gap**、可行性核验表、解结构稳健性。
- **真题落点**：2024C（三问递进大规模整数规划）、2023C 第三问（基数约束 MINLP）、2025A（投放时序优化）、2019C 第二问（调度方案）。
- **常见错法**：规模不大却用遗传算法且不报下界；漏掉跨期或跨对象耦合约束；多目标直接线性加权。

**规模分档（选路线依据是规模与结构，与题面看起来复杂无关）**：

| 问题规模与结构 | 求解路线 | 论文必须给出 |
|---|---|---|
| 变量数 ≤ 10⁵，线性或凸 | 精确求解（单纯形+分支定界，HiGHS/Gurobi） | 最优性证明或 gap |
| 变量数 10⁵~10⁶，或含非凸项 | 先松弛取下界，再定制启发式（列生成、拉格朗日松弛） | LP 下界与启发式解并列 |
| 变量数 > 10⁶，或目标为黑箱（仿真、不可微） | 元启发式：GA、PSO、SA、NSGA-II | 与下界的差距 + 收敛曲线 |

**gap 公式**：gap = (z_IP − z_LP)/z_LP × 100%。下料算例实证：枚举 689 个极大切割模式，HiGHS 整数最优 80 根，LP 松弛下界 79.36，⌈79.36⌉ = 80 → 最优性由此得证，gap = 0.81%。纯贪心稳定给 82 根；随机化贪心跑 200 次得 80 根 23 次、81 根 177 次——启发式碰到过最优解也无法自知，**作出判断的是 LP 下界**。没有 gap，评阅无法判断解离最优多远。

**多目标不要线性加权**：正确做法是给 Pareto 前沿再说明选点依据，或 ε-约束法逐点扫描。前沿的形状本身就是结论（例：切割模式种类数当第二目标，允许 1 种要 118 根，≥5 种降到 80 根，之后无收益——省料空间在前五种模式已用尽）。

### 2.8 随机与仿真类
- **题面特征**：要求给出概率、期望、风险度量，或对无法解析求解的系统做数值试验。
- **关键词**：概率、期望、方差、风险、可靠性、置信、抽样、检验、排队、等待、随机、模拟、仿真、蒙特卡洛。
- **数据特征**：存在随机源，或系统状态转移可描述但解析解不可得。
- **方法族**：概率分布拟合与假设检验 → 排队论与马尔可夫链 → 蒙特卡洛模拟 → 离散事件仿真 → 随机规划与鲁棒优化。
- **必报量**：**重复次数与随机种子、结果的置信区间、收敛性判据、分布假设的检验结果**。
- **真题落点**：2024B（抽样检验样本量与判定规则）、2019C（排队等待时间）、2024C 第二问（不确定性场景）。
- **常见错法**：仿真只跑一次就报结论；不给置信区间；分布假设不检验直接套公式。

## 3. 四组最容易混淆的类别

| 易混对 | 分界判据 | 判错的后果 |
|---|---|---|
| 聚类 vs 判别 | **有无标签**。题面给出类别定义与带标签样本 = 判别，否则聚类 | 把聚类结果当真实标签算准确率（指标无意义）；或对无标签数据强行训练分类器 |
| 回归 vs 预测 | **目标值是否落在训练数据取值范围内**。同分布内插 = 回归，时间外推 = 预测 | 用 R² 代替测试段误差，外推失效不被发现 |
| 评价 vs 判别 | 输出是**连续得分排序**还是**离散类别归属** | 评价题用分类器，权重不可解释；判别题用综合评分，阈值无依据 |
| 机理 vs 数据驱动 | 数据是否由已知规律产生，**参数是否有物理含义** | 放弃机理改用拟合，外推方向由多项式次数决定，结论不可信 |

| 概率／期望／可靠性 | | | | | | | | ● |
| 抽样／检验／置信 | | | | | ○ | | | ● |
| 排队／等待／服务 | | | | | | | | ●○ |
| 模拟／仿真／蒙特卡洛 | | | | | | | | ●○ |
| 不确定性／波动／风险 | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ |
| 灵敏度／稳健 | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ |

**两个易错点**：
1. 设问出现"预测"不代表整问是预测类——若后半句是"据此给出补货方案"，真正落点是**决策类**，预测只是中间量。
2. "分析影响因素"≠ 回归类——若要求给出因素重要性排序并据此分级，落点是**评价类**。

**跨类别判据**：题面出现"不确定性、波动、风险、灵敏度、稳健"，这些词不改变任务类型，但**该问必须补做灵敏度或稳健性分析，否则分值上限被锁死**（2024C 第二问评阅要点原话："应重点关注不确定因素分析的合理性与种植风险度量的适用性"）。

## 5. 把题面翻译成变量与约束（建模的实质动作）

**写下标就是建模**：`x_{p,c,s,t}` = 地块 p 在第 t 年第 s 季种作物 c 的面积——一旦定义清楚，目标函数与约束都是机械翻译。

2024C 约束翻译范本（最后两条被漏得最多，漏掉任意一条评阅即判不可行）：

| 题面限制 | 约束形式 |
|---|---|
| 每季总面积不超过地块面积 | Σ_c x_{p,c,s,t} ≤ A_p |
| 各类土地各自适宜的作物 | x_{p,c,s,t} = 0, c ∉ C_p |
| 同一地块不能连续重茬 | z_{p,c,s,t} + z_{p,c,s,t+1} ≤ 1 |
| 三年内至少种一次豆类（**跨年度覆盖约束**） | Σ_{τ=t}^{t+2} Σ_{c∈豆} z_{p,c,s,τ} ≥ 1 |
| 单作物每季面积不宜太小（**需 0-1 变量 + 大 M**） | x_{p,c,s,t} ≥ a_min·z_{p,c,s,t} |

**超出需求的处理要写进目标函数**（同一式子两个参数取值）：
max Σ [ p_c·min(Q, D) + α·p_c·max(Q−D, 0) ] − Σ k_c·x，其中 α=0 对应滞销浪费，α=0.5 对应五折出售。

**竞赛里绝大多数非线性项，三招线性化**：

| 题面写法 | 线性化做法 |
|---|---|
| min(Q,D) 或 max(Q−D,0) | 引入辅助变量 u，加 u≤Q、u≤D，目标为最大化时自动取紧 |
| "若种植则面积至少 a_min" | 引入 0-1 变量 z，加 a_min·z ≤ x ≤ M·z |
| "可售单品总数控制在 27~33 个" | 基数约束 27 ≤ Σz_i ≤ 33，问题变为混合整数规划 |

## 6. 整卷统筹：方法链与两个必查接口

三问串行的题，**选型必须整卷一起做**。范本 2023C：

| 问题 | 任务类型 | 方法 |
|---|---|---|
| 问1 | 关联 | 描述统计+分布拟合；销量非正态用 Spearman；品类间关联用聚类佐证 |
| 问2 | 预测+决策 | 需求价格弹性回归；销量时序预测（含节假日）；以收益最大为目标的非线性规划 |
| 问3 | 决策 | 0-1 变量选品+连续变量定量；混合整数非线性规划，或分解为选品与定量两阶段 |

**两个接口必须在开题时就查**：
1. **误差传递**：问2 的预测结果是问3 的输入——点值输入会让问3 的"最优解"继承预测误差却不显示它。正确做法：给**预测区间**，并在问3 做**区间端点的对照求解**。
2. **求解器切换**：问3 的基数约束使问题从连续规划变为混合整数（非线性）规划，沿用问2 的求解器会直接报不可行——开题时预留切换时间。

## 7. 十道真题选型对照（2018A–2025C）

| 赛题 | 各问任务类型 | 可行方法链 | 常见错法 |
|---|---|---|---|
| 2018A 高温作业专用服装 | 机理反演+优化 | 一维热传导方程差分求解，再以温度约束反解厚度 | 用回归拟合温度曲线，放弃机理，无法外推到新工况 |
| 2019C 机场出租车 | 随机+优化+评价 | 排队论估计等待时间，收益比较模型定策略，再做分区调度 | 只做描述统计，不建立司机收益比较模型 |
| 2020C 信贷决策 | 评价+聚类+优化 | 指标体系评信誉等级，再以收益最大做额度与利率分配 | 只评价不分配，或分配不写约束（额度上限、利率区间） |
| 2021B 乙醇偶合制 C4 烯烃 | 回归+机理+优化 | 方差分析与回归定影响因素，响应曲面拟合，再做条件寻优 | 几十组样本用神经网络，参数量远超样本量 |
| 2022C 古代玻璃成分 | 回归+聚类+判别 | 卡方检验与相关分析，层次聚类分亚类，判别模型定归属 | 用 Pearson 处理成分比例数据，忽略成分和为定值 |
| 2023B 多波束测线 | 机理+优化 | 几何覆盖宽度推导，再做测线间距的覆盖优化 | 直接启发式搜索，跳过几何推导，无法解析验证 |
| 2023C 蔬菜定价补货 | 回归→预测+优化→优化 | 相关分析；弹性回归+时序预测；混合整数非线性规划 | 三问各写各的，问2 点值预测直接喂给问3 |
| 2024C 农作物种植策略 | 优化，三问递进 | 大规模整数规划；问2 加不确定性场景；问3 加相关性 | 启发式代替精确解且不报 gap；漏豆类轮作与细碎化约束 |
| 2025A 烟幕干扰弹 | 机理+优化 | 遮蔽几何判定函数，再做投放时序与位置联合优化 | 遮蔽判定写成近似圆盘，几何误差直接传到优化结果 |

## 8. 六类高频误配（选型红色禁区）

| 常见做法 | 为什么不成立 | 替代方案 |
|---|---|---|
| 在 30 个样本上训练 LSTM | 参数量远超样本量，训练集误差趋零、测试段崩溃 | GM(1,1) 或 ARIMA，省下的篇幅给机理解释 |
| 对需外推的序列用树模型 | 预测值是叶节点均值，天花板锁死在训练段极值 | 先做趋势分解，树模型只拟合残差 |
| 评价题用神经网络综合评价 | 权重不可解释，评阅无法核验，样本量通常不足 | 熵权/CRITIC + TOPSIS，篇幅给指标方向与量纲 |
| 类别 9:1 失衡时直接看准确率 | 全判多数类即得 90%，指标失效 | 报 F1、AUC 与召回，并说明阈值如何选 |
| 整数规划规模不大却用遗传算法 | 把可精确求解的问题降级为近似求解，无法证明最优性 | 先解 LP 松弛得下界，再决定要不要启发式 |
| 多目标直接线性加权成单目标 | 权重缺乏依据，无法呈现权衡关系 | 给 Pareto 前沿，或 ε-约束法逐点扫描 |

**选型自查三句话**（每问过一遍）：
1. 这个方法**要求多少样本**，我有多少？
2. 这个方法**能不能外推**，题目要不要外推？
3. 这个方法的输出**能不能被评阅人核验**？

## 9. 赛题结构趋势与选题概率账（配合 13b 使用）

- **C 题的优化成分在快速上升**：2023 前普遍 <25%，2023C（蔬菜定价补货）升到 40%，2024C（农作物种植策略）升到 80%。**只练数据预处理与预测模型，2024 那一卷从第一问起就难以推进——现在的 C 题必须会写整数规划**。
- **A 题机理成分长期稳定在 40% 以上**且要求可推导；2025A 是几何遮蔽判定+投放时序优化，机理与优化各半。
- **B 题形态最不稳定**（2023 纯几何+覆盖优化；2024 抽样检验+多阶段决策；2025 光学干涉参数反演）。准备 B 题等于准备任何题，性价比最低。
- **国赛选题机制**：按《赛区评阅工作规范》，**同一学校每道赛题报送全国评阅不超过 4 篇，其中申报一等奖不超过 2 篇**。本校 30 支队做 C 题与 6 支队做 A 题名额相同——前者校内竞争强度是后者 5 倍。**顺序：先判断本校在哪一题不处于劣势（可查：本校历年各题国奖数量、指导教师专长），再判断自身在哪一题有把握完成。全国口径的难度排序对个人决策几乎没有参考价值。**（美赛则相反：按题目均分名额，避开人数最多的题直接改善期望——2026 MCM C 题 13185 队 O 奖率 0.144%，F 题 1776 队 0.225%。）

## 10. 本文件要点（判断自己是否学会）

1. 判定分三层：输出定类型 → 三处二次判定（外推/机理/标签）定分支 → 方法族最后由数据条件确定。
2. 八类任务各有**必报量**，写不出必报量的那一类 = 类型判错了。
3. 聚类与判别分界 = 有无标签；回归与预测分界 = 是否外推；评价与判别分界 = 输出连续还是离散。
4. 机理类不能用曲线拟合替代（外推 RMSE 差 5.5 倍 + 非物理结果 + 参数无含义）。
5. 预测类先判外推：测试段超出训练段范围比例 >10%，树模型不能单独用（天花板锁死是模型结构决定的，调参无效）。
6. 评价类的风险点在**指标方向与量纲**（赋权法互换排名一致性 0.9762；方向改判 96.6% 名次变动）——赋权法论证 ≤3 行。
7. 优化类先解 LP 松弛得下界；整数规模不大就精确求解并报 gap；多目标给 Pareto 前沿，不做加权求和。
8. 随机仿真必报：重复次数+种子+置信区间+收敛判据+分布假设检验。
9. 题面出现"不确定性/波动/风险/稳健"→ 该问必补灵敏度/稳健性分析。
10. 选型自查三句话：样本够不够、能不能外推、输出可不可核验。
