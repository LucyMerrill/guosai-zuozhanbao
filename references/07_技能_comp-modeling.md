> 用途：国赛流程 ② 阶段调用。读题后产出"可求解、可验证"的模型方案。
> 配套：填 `01_研究契约模板.md`、`03_实验计划模板.md`；自检守本技能末尾清单。
> **2026-08-28 升级**：判型与选型第一裁决改为 `21_赛题识别八类任务判据.md`（八类判据+必报量+四组易混+高频误配）；方法细节第一参考改为 `22_题型流程化解题手册.md`；本文件保留国赛专项约束层。
> **协作**：配合已装（ZCode ~/.zcode/skills/）`math-modeling-solver` 使用——`solver` 提供 95+ 模型矩阵与 Playbook 方法深度，本文件提供国赛专项约束（可解释性铁律 / 问题分析章 / 基线对比），不重复造轮子。

## 触发
用户说"按作战包 ② 建模"或给题后要求建模。先确认 `01_研究契约` 已填（未填则先引导填空）。

## 目标
把自然语言赛题，转化为**数学上可求解、物理上合理、评审上可辩护**的模型，并给出明确的求解路径与验证方案。

## 输入
- 赛题原文 / 题目 PDF
- 已有数据（若有）
- `01_研究契约模板.md`（用户填好的范围）

## 执行步骤

### 1. 读题三遍（不跳）
- 一遍抓**目标**：到底要预测/优化/评价/分类/仿真什么？
- 二遍抓**条件**：已知量、约束、数据可得性。
- 三遍抓**交付**：要交什么（数值/方案/排名/策略）。
- 输出一句话："本题本质是 ______ 类问题。"
- **判定纪律（21 号）**：先判"要什么"再判"用什么"；**按问判定不按题判定**；逐问做三处二次判定（是否外推 / 机理是否已知 / 有无标签）；题面出现"不确定性/波动/风险/稳健"→ 登记该问必补灵敏度分析。

### 2. 问题归类 → 选模型（决策矩阵）
**第一裁决 = `21_赛题识别八类任务判据.md` §2**（机理/预测/回归关联/评价/判别/聚类/优化/随机，每类的题面特征、关键词、方法族、必报量、真题落点、常见错法）。速查简表（详表以 21 号为准）：

| 问题本质 | 首选模型族 | 典型方法 |
|----------|-----------|----------|
| 评价/打分 | 综合评价 | 正向化+熵权/CRITIC/AHP → TOPSIS/加权和（赋权论证 ≤3 行，方向量纲才是得分点） |
| 优化决策 | 数学规划 | 线性/整数/非线性规划、多目标(Pareto 前沿/ε-约束/NSGA-II) |
| 预测/拟合 | 回归/时序 | 先判外推：参数化趋势/ARIMA；不外推样本足才用 RF/XGBoost |
| 分类/判别 | 机器学习 | Logistic→LDA→树集成→SVM（有标签才叫判别） |
| 聚类分组 | 无监督 | 先标准化；K-Means/层次/DBSCAN/GMM/谱（五族选择见 22 号 §3） |
| 网络/关系 | 图论 | 最短路、最大流、社区发现 |
| 演化/连续 | 微分方程 | 常/偏微分、agent-based 仿真 |
| 排队/随机 | 随机过程 | 排队论、蒙特卡洛（必报重复次数+种子+CI） |

> 不确定时调用 `math-modeling-solver` 知识库做题型判定；不要堆砌模型。
> **选型后逐条过 21 号 §8 六类高频误配与自查三句话（样本够不够 / 能不能外推 / 输出可不可核验）。**

#### 2.0 选型硬规则（2026-08-28 新增，全部来自 21 号实证）
- **外推判据**：测试段目标值超出训练段 [min,max] 的样本比例 >10% = 需外推 → 禁止单独用树模型（其预测值被训练段极值锁死，调参无效），先趋势分解再对残差用 ML。
- **机理题禁曲线拟合替代**：拟合段几乎无差、外推 RMSE 差 5.5 倍且多项式外推出非物理结果；机理反演的参数本身就是论文卖点。
- **优化规模分档**：变量 ≤10⁵ 精确求解（报最优性/gap）；10⁵~10⁶ 先 LP 松弛取下界再定制启发式（列生成/拉格朗日）；>10⁶ 或黑箱才用元启发式（报与下界差距+收敛曲线）。
- **多目标禁直接线性加权**：给 Pareto 前沿 + 选点依据，或 ε-约束法。
- **评价题得分点在指标方向与量纲**（改判一个方向 → 96.6% 样本名次变动；换赋权法排名几乎不变 0.9762）——赋权法论证 ≤3 行。
- **题面翻译**：用"写下标"法定义变量（如 x_{p,c,s,t}），约束逐条机械翻译；跨期覆盖约束与 0-1+大M 细碎化约束最易漏；非线性项三招线性化（辅助变量 / 0-1+大M / 基数约束），见 21 号 §5。
- **整卷统筹**：多问串行必须整卷一起做选型；查两个接口——误差传递（上游预测给区间，下游做区间端点对照求解）、求解器切换（连续→混合整数需换求解器，开题时预留时间）。

### 2.1 模型可解释性优先级（国赛铁律）
- 国赛评委多为高校教师，**看不懂、也不信任"炼丹式"黑箱**。评审标准明确看重"假设合理性、模型创新性、灵敏度/误差分析"——黑箱算法这三样都难交代清楚，易被判定为"套模型"。
- **默认优先白盒 / 弱黑箱模型**：机理模型、统计模型（回归 / ARIMA / PCA / 熵权 / AHP / TOPSIS / 微分方程 / 整数规划）一律首选。它们有清晰因果链、数学可推导、易做灵敏度与误差分析。
- **黑箱（深度学习 / XGBoost / 随机森林 / 神经网络）仅在同时满足以下条件时使用**：
  1. 问题本质确为高维非线性拟合 / 分类，且白盒模型明显不够用（多出现于 C 题大数据场景）；
  2. 必须先跑一个可解释模型作 **baseline**（见 §5），黑箱结果要与之对比、说明"为什么更好"，而非孤立炫技；
  3. 必须配可解释手段：特征重要性、SHAP，或至少给出"哪几个因子主导结果"的定性结论；
  4. 绝不把黑箱当作唯一论证——最终结论的因果仍要用机理 / 统计语言解释。
- 规律（来自 A/C 题国奖复盘）：2024 A 板凳龙全程白盒机理 + 几何 + 优化；2023 C 蔬菜用统计时序 + 运筹优化，并未堆黑箱。黑箱用得好也能拿奖，但那通常是"结合机理（如 PINN）或做足对比"的少数情况，不宜作为默认策略。

### 2.2 建模篇常见失分点（对应 123 条 1–41，必守）
- **选型**：定题 ≤2h 且定后不横跳（第1–2条）；模型**适配性优先于复杂度**（第3条），绝不为凑创新硬加无关模型（第4条）。
- **假设**：逐条标注「合理性假设 / 简化性假设」并分别说明理由（第6条）；所有假设有现实依据（第5条）。
- **问题拆解**：严格对应设问，不漏问/不跳问/不加戏（第7条）；多小问递进复用前问、各有承接与区分（第10–11条）。
- **优化类**：必须写出目标函数并说明实际意义；约束区分硬/软并全列（第8–9条）。
- **赋权**：主观讲依据、客观标来源与逻辑、组合讲原理与占比；最后**校验权重和为 1**（第16–19条）。
- **验证**：预测必带具体误差指标、必做敏感性分析、随机类重复取平均（第21–24条）；仿真设合理对照组（第34条）；概率统计类先验证分布假设（第35条）。
- **表达纪律**：单位全程统一（第31条）、符号前后一致（第32条）；小样本不硬套深度学习（第36条，呼应 §2.1）；最终结果做常识性校验，违背现实逻辑必须重算（第41条）。

### 2.5 写「问题分析」逐问拆解（必须落纸为独立写作章节，对齐问题驱动结构）
- 对赛题每个子问题单独写：**已知什么、要解什么、从哪几个角度切入、用哪类方法**。
- 画一张「各问题递进关系 + 求解流程图」（国奖论文标配，图题≤15字）。这一步锁死思路、防止建模跑偏——作战包要求它成为论文独立章节「二、问题分析」（见 `10`/`17 §3`），不只是内部思考。
- **结构意识（对标 C050 / 17 §3）**：最终论文是**问题驱动**——「每问一章《问题 N 模型的建立与求解》，章号随问数顺延（六~九为四问题示例）」各成章，每章内按"数据预处理→建模→求解→结果"组织；「五、数据侧写」单列顶层章。建模时就要按"每个子问题一套建模求解闭环"来设计，而非"全局建立/求解/结果"三段式。

### 3. 写假设（三条硬标准 + 模板六类来源）
每条假设必须同时满足：**必要**（不假设就建不了）、**合理**（贴近实际）、**可检验**（能验证是否成立）。
- **六类来源（来自国赛模板批注，按此找假设不漏）**：① 题目明确给出的条件；② 排除生活中的小概率事件（黑天鹅、非正常情况）；③ 仅考虑核心因素、忽略次要因素；④ 所用模型本身要求的假设（如回归的独立性、ARIMA 的平稳性）；⑤ 对模型参数形式（或分布）的假设；⑥ 与题目联系紧密、为简化模型而设的假设。
- 数量 **4~6 条**；越合理、越靠前（对应前问）的放前面；每条附一句理由；凑数的水假设最多 1 条。
- 列假设清单 + 符号表（全文符号无歧义、一致；符号说明表只收重要变量，临时变量不收，但变量在正文首次出现处仍要解释）。
- 删掉"为建模方便"的硬伤假设。

### 4. 模型建立（数学化 + 可求解）
- 用公式把问题写清楚：目标函数 / 约束 / 状态方程。
- 关键：**写出的方程必须能算出结果**，避免"列了算不出"的空中楼阁。
- 给出求解算法步骤（输入→处理→输出），注明用什么工具（Python / 现成库）。

### 5. 求解路径与验证设计
- 数值方法选型（解析/数值迭代/优化器）。
- 设计**正确性验证**：已知特例、量级估计、与解析解对比。
- 设计**灵敏度/误差分析**：关键参数扰动看结果稳定性（落进各问题章的"结果分析"与「十、评价与推广」，不单列大章）。
- 设计**基线对比**：先给出朴素/常规解法结果作 baseline，再说明本模型相对 baseline 的提升，证明方法有效（对应国奖论文"与平均情况对比发现收益提升"的做法）。
- 设计**数据侧写**：每个附件先列字段/样本量，再观测分布/季节/异常特征，作为「五、数据侧写」与每问题章"数据预处理"的输入。
- 把以上写进 `03_实验计划模板.md`（Claim 映射 + 实验块 + 成功判据）。
